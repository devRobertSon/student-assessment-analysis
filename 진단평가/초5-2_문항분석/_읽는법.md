## 파일 머리

```
# 초5-2 {단원 이름 또는 원본 이름} 문항 분석

답과 풀이는 원본 PDF 뒤쪽 해설 쪽에서 확인했다.

이 단원의 개념은 이렇다.        ← 단원 TEST 파일에만

{개념 · 개념 · 개념 …}

---
```

A~E 파일은 개념 줄 대신 `단원별로는 {단원} {수} · … 이다.` 를 적는다.

## 문항 하나

```
## 단원1-07                       ← A~E 는 `## 심화형-07 · 수의 범위와 어림하기`
                                    선지가 없는 문항은 끝에 ` (주관식)`

**문항** {문제를 글로 옮긴다. 수식은 `백틱` 안. 선지는 ① ② … 그대로.
그림은 (그림: …) 으로 읽은 것을 적는다}

**답** {객관식은 `③ 15` 처럼 번호와 값. 정답이 둘이면 `②, ③`. 주관식은 값}

**풀이**

1. {한 줄이 한 단계}
2. …

**주 유형** {여덟 유형 중 하나}

{N단계에서 틀린다. 틀린 학생이 무엇을 못 해서 틀리는지 두세 문장}

**부 유형** {여덟 유형 중 하나 또는 없음}

**난이도** {표준 · 상 · 최상}

**묶음** {이 단원 개념 이름을 `+` 로 이어 가나다 순}

**겹침 표시** {같은 그림에 숫자만 바꾼 것 · 푸는 길이 같은 문항 이름. 없으면 이 줄을 뺀다}

**핵심 풀이** {결정적인 한 수를 한 구절로}

(뼈대: {푸는 차례를 한 줄로})

---
```

## 기준

**글.** 문장은 `~다.` 로 끝내는 평서문이다. 대분수는 `2 1/4` 처럼 정수와 분수
사이를 한 칸 띄운다. 분수는 `3/7`, 곱하기는 `×`, 나누기는 `÷`. 단위는 그대로
적는다(`cm²`, `m³`, `L`).

**여덟 유형.** 주 유형은 **그 문항을 틀린 학생이 못 한 것 하나**다. 답을 내기
직전에 한 일이 아니다(그렇게 하면 어려운 문항이 다 연산 처리가 된다).
부 유형은 주 유형을 해낸 학생이 그다음으로 걸리는 것이고, 한 걸음으로 끝나는
문항은 `없음`.

| 유형 | 재는 것 |
|---|---|
| 연산 처리 | 식을 정확히 계산하는 것 |
| 공식 활용 | 어떤 공식을 쓸지 고르고 넣는 것 |
| 개념 이해 | 정의와 성질을 아는 것 |
| 표현 해석 | 그래프와 표, 그림, 새 기호를 읽는 것 |
| 규칙 발견 | 나열하고 관찰해 규칙을 찾는 것 |
| 근거 제시 | 참·거짓을 가리고 근거를 대는 것 |
| 단계별 해결 | 두 단계 이상을 엮어 끝내는 것 |
| 식 설정 | 문장에서 모르는 수를 정하고 식을 세우는 것 |

**난이도** (2026-09-20 원장님 확인)

| 난이도 | 기준 |
|---|---|
| 표준 | 이 단원에서 배운 절차를 그대로 쓰면 답이 나온다 |
| 상 | 조건이나 식을 학생이 스스로 세워야 한다 |
| 최상 | 두 개념을 순서로 써야 한다 |

**묶음**은 그 문항을 푸는 데 쓰는 **개념의 조합**이다. 단원에서 이름이 붙은
개념만 세고, 사칙계산처럼 어디에나 들어가는 것은 세지 않는다. 조합이 똑같아야
같은 묶음이다. 같은 조합에는 늘 같은 글자를 쓴다.

**뼈대**는 푸는 차례를 한 줄로 적은 것이다. 묶음이 같아도 묻는 방법이 다르면
뼈대가 다르다.

**핵심 풀이**는 그 문항을 푸는 결정적인 한 수다. 그 한 수를 아는 학생은 풀고
모르는 학생은 못 푸는 자리다. 숫자 · 문장 · 앞뒤에 붙은 한 단계는 보지 않는다.
같은 한 수에는 같은 글을 쓴다. 같은 공식을 다른 목적에 쓰면 다르다.

**겹침 표시**는 같은 파일 안에서, A~E 파일은 다른 파일의 같은 단원 문항과도
본다. 같은 그림에 숫자만 바꾼 것, 푸는 길이 같은 것을 서로 걸어 둔다.
