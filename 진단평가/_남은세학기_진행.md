## 곱하기 x 를 문자 x 까지 바꾸던 것을 고쳤다 (2026-09-21)

`mkspec.py` 의 `clean()` 이 백틱 안의 ` x ` 를 모두 `×` 로 바꾸고 있었다.
중1-2 해설에 `25 + x = 35` 가 `25 + × = 35` 로 인쇄되고 있었다. 앞뒤에 셈
기호(`= + - < > ≤ ≥ : ,`)가 붙어 있으면 문자로 보고 두도록 고쳤다.

네 학기 스펙을 모두 다시 훑어 남은 자리가 없는 것을 확인했다. 중2-1 해설에서
두 군데(`6 < × < 9`, `2 - × >= 5`)가 고쳐졌고 중1-1 과 중2-2 는 원래 없었다.

**문항 분석 문서에 `**` 를 쓰지 않는다.** 조판기는 글자를 그대로 찍으므로
`**처음으로**` 가 별표까지 인쇄된다. 중2-1 에서 두 군데를 고쳤다.
