# 출처 코드

이 폴더의 글에서 문제마다 어디서 왔는지 적는다. 교재는 앞으로 더 늘어난다.
새 교재를 쓰기 전에 **먼저 여기에 코드를 만들고** 그 코드로 적는다.

## 적는 법

문제 제목 줄 끝에 괄호로 붙인다. 유형 표시 뒤다.

```
**문제 1.** `개념 이해` `적용` (옛자료2 27쪽 문제 2)
**문제 3.** `탐구 설계` (하이탑1-1 062쪽 서술형 6)
**문제 5.** `결론·일반화` (새로)
```

쪽번호는 **교재에 찍힌 쪽번호**를 쓴다. PDF 의 몇 번째 장인지가 아니다.

적는 예:

```
(영재22연합 세종 1번)
(과학고23부산 2번)
(세페이드2F화학상 024쪽 창의력 03)
```

한 파일에 여러 해가 든 과학고 기출(`2017-2020학년도 한성과학고.pdf` 등)은 문제에
찍힌 학년도로 코드를 짓는다. 충북과학고 2021학년도 두 파일은 `과학고21충북개방`,
`과학고21충북융합` 이다. 한 파일 안에서 영역이나 문항지마다 번호가 새로 시작하면
영역 이름을 붙인다: `(과학고23경기북 자기주도2 1번)`, `(과학고24대전동신 A 2번)`.

## 교재를 더할 때

1. 원본 PDF 를 `원본/` 에 둔다.
2. 위 표에 코드를 한 줄 더한다. 코드는 `교재이름학년-권` 꼴로 짧게 짓는다.
3. 그 교재에서 가져온 문제부터 새 코드로 적는다.

**이미 적어 둔 출처는 고치지 않는다.** 교재가 늘어도 옛 표시는 그대로 맞는다.

## 교재 문제를 이 폴더로 옮기는 기준

| 교재의 자리 | 이 폴더로 |
|---|---|
| 서술형 문제 (중단원 끝) | **가리키는 표로 넣는다.** 문제 요지와 Keyword, 유형만 적고 본문은 교재를 편다 |
| 최상위권 도전 문제 (대단원 끝) | 넣지 않는다. 영재성평가 시험지를 만들 때 참고한다 |
| 논술형 문제 (대단원 끝) | 넣지 않는다. 영재성평가 시험지를 만들 때 참고한다 |
| 개념 확인 문제 | 넣지 않는다 |
| 실력 강화 문제 | 넣지 않는다 |

서술형 문제를 본문째 옮기지 않는 까닭은 사진과 그림에 기대는 문제가 많아서다.
글만 옮기면 풀 수 없다. 대신 **Keyword 를 그대로 적어 둔다.** 채점할 때 쓰는 낱말이고,
영재성평가 채점 기준을 만들 때도 본이 된다.

## 영재·과학고 대비 교재에서 모으는 기준

학년마다 `중*/_교재_영재대비.md` 에 단원별로 모은다. 하이탑 색인과 같이
**저장소로 옮기지 않는다.**

| 자료 | 모으는 것 |
|---|---|
| 영재학교 기출, 두 모의고사 | 과학 문항 전부 |
| 영재과학고 기출예상문제 네 영역 | 장마다 있는 「출제예상문제」 전부. 앞의 개념 정리 쪽은 넣지 않는다. 출처는 책에 찍힌 쪽과 문항 번호로 `(기출예상물리 014쪽 01번)` 처럼 적는다. 같은 책 모의고사는 영역마다 번호가 새로 시작해 `(기출예상모의1 물리 1번)` 처럼 적는다 |
| 과학고 기출 | 과학 문항만. 면접 문항이라 수학·인성 문항이 섞여 있어 뺀다. 과학 문항 안의 수학·인성 소문항은 표에 두고 유형 칸에 `수학(유형 없음)` 처럼 적는다. 같은 해 두 파일에 같은 문항이 있으면 한 번만 넣고 비고에 적는다 |
| 세페이드 2F·3F | 「창의력 & 토론마당」 전부, 「스스로 실력 높이기」 끝의 「창의력 서술」, 대단원 끝 Project. Project 는 논/구술·서술 물음과 뒤에 붙은 탐구 쪽까지 넣는다. 개념확인·유형 익히기·객관식은 넣지 않는다 |
| 사고력과학 | 문제를 기출에서 가져온 책이다. 기출과 겹치면 기출 쪽 비고에 사고력과학 쪽수를 적고, 기출 폴더에 없는 문제만 `사고력1` 같은 코드로 넣는다 |

표는 `출처 | 요지 | 유형 | 비고` 네 칸이다. 이 교재들에는 하이탑 같은 Keyword 가
없다. 채점 기준은 해설지를 편다.

- 여러 단원을 함께 쓰는 문제는 **가장 늦게 배우는 단원**에 두고 나머지 단원은
  비고에 적는다.
- 중3 내용이 필요한 문제는 버리지 않고 중3 파일에 둔다. 중3 과정도 만든다.
- 고등 과정 내용이 들어 있으면 비고에 `고등` 이라고 적고 가장 가까운 중학 단원에 둔다.
- 유형은 **소문항마다** 붙인다. 시험지를 소문항 단위로 채점하기 때문이다.
  `` (1) `적용` (2) `자료 변환·해석` `` 처럼 적고, 소문항이 없는 문제는 유형만 적는다.
  번호 붙은 소문항 없이 답안란이 ◆ 칸이나 ■ 칸으로 나뉜 문제는 칸을 ◆1, ◆2(■1, ■2)
  로 적고 유형도 칸마다 붙인다(25경기 ◆, 24경기 ■). 같은 것을 묻는 빈칸이 여럿이면
  ■1~■5 처럼 묶어 적는다.
- 세페이드 Project 는 한 행에 적는다. 논/구술·서술 물음을 (1), (2) 로 적고, 탐구 쪽 물음은
  쪽 순서대로 번호를 이어 붙인다. 탐구 쪽의 빈칸·단답·결과 표·선다형도 소문항마다 유형을
  붙인다.
- 난이도와 유형 근거는 시험지를 만들 때 정한다.
