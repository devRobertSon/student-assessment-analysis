# 중1 Ⅶ. 태양계

| | |
|---|---|
| 교재 | `하이탑1-2` 096~143쪽 |
| 최상위권 도전 문제 | `하이탑1-2` 132쪽 |
| 논술형 문제 | `하이탑1-2` 136쪽 |
| 옛 자료 | `옛자료2` 14~20쪽 (3단원 태양계) |

15개정에서 중2 이던 단원이 중1 로 내려왔다. 중단원이 셋(지구의 크기와 운동 · 달의
크기와 운동 · 태양계의 구성)에서 **둘(태양계의 구성 · 지구와 달)로 줄고 차례가
뒤바뀌었다.** 태양계 전체를 먼저 보고 지구와 달로 좁혀 들어가는 짜임이다.

## 01. 태양계의 구성

| | |
|---|---|
| 교재 | `하이탑1-2` 098~113쪽 |
| 옛 자료 | `옛자료2` 20쪽 (3단원-03 태양계의 구성) |

옛 자료의 이 중단원에는 **학습 목표가 없고 문제만 있다.** 22개정 교재 내용에 맞춰
학습 목표를 새로 적었다.

### 학생들의 추가 학습 목표

1. 항성과 행성의 차이를 설명할 수 있고, **행성이 되기 위한 세 조건**을 말할 수 있어야
   합니다. 명왕성이 어느 조건에 걸려 행성에서 빠졌는지까지 이어 말해야 합니다.

2. 태양계 행성을 나누는 기준 두 가지를 알고, 물리적 특성 다섯 가지 이상으로 지구형과
   목성형을 부등호로 비교할 수 있어야 합니다.

3. 태양의 흑점이 주위보다 온도가 낮은 까닭과, 흑점 수가 많아질 때 지구에 나타나는
   현상을 설명할 수 있어야 합니다.

4. **심화:** 태양 대기(코로나, 홍염)를 언제 볼 수 있는지 알고, 흑점 수와 태양 대기의
   크기가 함께 변하는 까닭을 생각해 볼 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` `결론·일반화` (옛자료2 20쪽 문제 1)
천체에 대해 답하시오.

1. 항성과 행성이 무엇인지 적으시오.
2. 행성이 되기 위한 조건 세 가지를 설명하고, 명왕성이 행성에서 빠진 까닭을 적으시오.

**문제 2.** `자료 변환·해석` `적용` (옛자료2 20쪽 문제 2)
태양계 행성의 분류에 대해 답하시오.

1. 태양계 행성을 나누는 기준 두 가지를 적고, 각 기준으로 나뉜 행성들을 부르는 이름을
   적으시오.
2. 물리적 특성에 따라 나눌 때 기준이 될 수 있는 특성을 다섯 가지 이상 적고, 어느 쪽이
   더 큰지 부등호로 비교하시오.

**문제 3.** `결론·일반화` (옛자료2 20쪽 문제 3)
지구에서 볼 때 가장 밝게 보이는 행성을 적고 까닭을 설명하시오.

**문제 4.** `개념 이해` `적용` (옛자료2 20쪽 문제 4)
태양의 흑점에 대해 답하시오.

1. 흑점이 무엇인지 주위와의 온도 차이를 넣어 설명하시오.
2. 흑점 수가 많아질 때 나타나는 현상을 설명하시오.

### 교재 서술형 문제

`하이탑1-2` 112~113쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 02. 지구와 달

| | |
|---|---|
| 교재 | `하이탑1-2` 114~131쪽 |
| 옛 자료 | `옛자료2` 14~16쪽 (지구) · `옛자료2` 17~19쪽 (달) |

15개정의 중단원 **둘이 하나로 합쳐졌다.** 옛 자료의 분량이 많아 이 중단원에 문제가
가장 많이 모인다.

### 학생들의 추가 학습 목표

1. 에라토스테네스가 지구의 크기를 잰 방법을 설명할 수 있고, 그 과정에서 생긴 오차와
   오차가 생긴 까닭을 설명할 수 있어야 합니다.

2. 태양의 연주 운동과 천체의 연주 운동을 **상대적인 운동**으로 설명할 수 있어야 합니다.

3. 24시간의 기준이 천구 위 태양의 위치임을 알고, 지구가 360도 자전하는 시간이 24시간보다
   짧다는 것을 알아야 합니다. 이 때문에 황도가 1년에 지구 둘레를 한 바퀴 돈다는 것까지
   이어 말할 수 있어야 합니다.

4. 태양의 일주권이 1년 동안 어떻게 변하는지 알고, 그래서 하지에 남중 고도가 가장 높고
   동지에 가장 낮다는 것을 알아야 합니다.

5. 달의 크기를 재는 방법 두 가지를 설명할 수 있어야 합니다.

6. 일식과 월식이 일어나는 조건과 진행 차례를 정확하게 설명할 수 있어야 합니다.

7. **심화:** 삭망월과 항성월의 차이를 설명할 수 있어야 합니다.

### 문제

**문제 1.** `탐구 설계` `결론·일반화` (옛자료2 15쪽 문제 1)
에라토스테네스는 시에네의 우물과 알렉산드리아 신전 기둥의 그림자로 지구의 크기를
측정하였다.

1. 측정 원리를 설명하시오.
2. 오차로 다음 두 가지가 주어져 있다. 추가로 오차 두 가지를 적고 까닭을 설명하시오.
   - 두 지점 사이 거리를 발걸음으로 재어 생긴 오차
   - 실제 지구가 구형이 아니라 타원체인 것

**문제 2.** `개념 이해` `적용` (옛자료2 15쪽 문제 2)
지구의 자전에 대해 답하시오.

1. 지구는 시계 반대 방향으로 자전한다. 어느 시점에서 볼 때 시계 반대 방향인지 구하시오.
2. 지구 둘레를 한 바퀴 돌면 서쪽이 동쪽이 되는데도 왜 서에서 동으로 자전한다고 하는지
   설명하시오.
3. 자전 속도는 1시간에 약 몇 도인지 구하고 과정을 설명하시오.
4. 우리나라에서 북쪽·남쪽·동쪽·서쪽 하늘을 볼 때 천체의 일주 운동 방향을 각각 적으시오.

**문제 3.** `자료 변환·해석` `결론·일반화` (옛자료2 16쪽 문제 3·4)
지구의 공전에 대해 답하시오.

1. 공전 방향을 구분하고 확인할 수 있는 방법을 적으시오.
2. 공전 속도가 하루에 약 몇 도인지 구하고 과정을 설명하시오.
3. 별의 연주 운동 방향과 태양의 연주 운동 방향이 반대인 까닭을 설명하시오.
4. 황도가 무엇인지 적으시오.
5. 황도와 태양의 일주권 사이 각도를 계산하고 과정을 설명하시오.
6. 천체가 남중한다는 뜻을 설명하고 태양의 남중 고도를 구하는 까닭을 설명하시오.

**문제 4.** `개념 이해` `탐구 설계` (옛자료2 18쪽 문제 1)
달의 크기를 재는 방법으로 삼각형의 닮음비를 쓰는 방법과 각지름을 쓰는 방법이 있다.
두 방법을 쓸 때 먼저 알아야 할 것을 각각 적으시오.

**문제 5.** `자료 변환·해석` `결론·일반화` (옛자료2 18쪽 문제 2)
달의 공전에 대해 답하시오.

1. 공전 방향을 구분하고 확인할 수 있는 방법을 적으시오.
2. 공전 속도가 하루에 약 몇 도인지 구하고, 그 때문에 달이 뜨는 시각이 어떻게 달라지는지
   적으시오.
3. 「달의 공전으로 달이 뜨는 시각이 달라진다면 지구의 공전으로 태양이 뜨는 시각도
   달라져야 한다」는 문장이 맞는지 까닭과 함께 밝히고, 틀렸다면 고쳐 쓰시오.
4. 삭 → 초승달 → 상현달 → 보름달 → 하현달 → 그믐달 → 삭의 음력 날짜와 남중 시각을
   각각 적으시오.

**문제 6.** `개념 이해` `결론·일반화` (옛자료2 19쪽 문제 3)
일식과 월식에 대해 답하시오.

1. 각각 무엇인지 적으시오.
2. 일어날 때 달의 위상을 각각 적으시오.
3. 매달 일어나지 않는 까닭을 설명하시오.
4. 한 지역에서 어느 쪽이 더 자주 보일지 짐작하고 까닭을 설명하시오.
5. 금환식이 무엇인지 설명하고 일어나는 까닭을 설명하시오.

**문제 7.** `개념 이해` (옛자료2 19쪽 문제 4·5)
항성월과 삭망월이 각각 무엇인지 적고, 두 값이 일치하지 않는 까닭을 설명하시오. 또 달의
자전 속도가 하루에 약 몇 도인지 구하고, 공전 속도와 자전 속도가 같아서 나타나는 현상을
적으시오.
