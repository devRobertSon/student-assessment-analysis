# 중1 Ⅴ. 힘의 작용

| | |
|---|---|
| 교재 | `하이탑1-2` 006~053쪽 |
| 최상위권 도전 문제 | `하이탑1-2` 042쪽 |
| 논술형 문제 | `하이탑1-2` 046쪽 |
| 옛 자료 | `옛자료1` 7~10쪽 (2단원 여러 가지 힘) · `옛자료3` 18~19쪽 (3단원-01 운동) |

15개정에서 중1 의 「여러 가지 힘」과 중3 의 「운동」이 **한 대단원으로 묶였다.**
두 학년을 건너뛰어 합쳐진 자리라 옮기면서 가장 많이 손댄 단원이다.

---

## 01. 여러 가지 힘

| | |
|---|---|
| 교재 | `하이탑1-2` 008~031쪽 |
| 옛 자료 | `옛자료1` 7~8쪽 (중력과 탄성력) · `옛자료1` 9~10쪽 (마찰력과 부력) |

### 학생들의 추가 학습 목표

1. 과학에서 힘은 **작용하는 점, 크기, 방향** 세 가지로 나타냅니다. 중력, 탄성력,
   마찰력, 부력을 모두 이 세 가지로 나누어 설명할 수 있어야 합니다. 크기는 「무엇에
   따라 정해지는가」까지 말해야 합니다.

2. 실생활에서 탄성력, 마찰력, 부력을 이용한 예를 최대한 많이 찾고, 각 예에서 그 힘을
   어떤 쓸모로 썼는지 말할 수 있어야 합니다.

3. 아르키메데스의 원리(부력의 크기는 잠긴 부피만큼의 액체나 기체의 무게와 같다)를
   설명할 수 있어야 합니다.

4. **심화:** 힘의 평형에서, 용수철에 매달린 추가 멈춰 있을 때 **추가 아니라 용수철에서의
   힘의 평형**을 설명할 수 있어야 합니다. 용수철의 무게를 무시할 수 있을 때입니다.

5. **집중분석:** 추의 개수가 아니라 **용수철의 개수와 배치**를 바꿀 때 각 용수철이
   늘어난 길이와 전체 길이가 어떻게 달라지는지 생각해 볼 수 있어야 합니다.
   `하이탑1-2` 042쪽 최상위권 도전 문제 2번과 같은 자리입니다.
   1) 용수철을 위아래로 이어 매달고 맨 아래에 추를 달 때
   2) 용수철을 좌우로 나란히 놓고 추를 나눠 달 때
   3) 용수철, 추, 용수철, 추 차례로 위아래로 이어 달 때

6. **심화:** 빗면에 놓인 수조가 한쪽으로 힘을 받아 움직일 때, 잠긴 물체에 작용하는
   부력의 방향은 중력의 반대 방향이 아니라 **물체에 작용하는 힘의 반대 방향**임을
   생각해 볼 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` (옛자료1 8쪽 문제 1·2·3·5·7)
다음을 적으시오.

1. 과학에서 힘의 뜻
2. 물체에 힘이 작용할 때 변할 수 있는 것을 모두
3. 중력의 뜻, 크기, 방향
4. 무게와 질량의 차이
5. 탄성력의 뜻, 크기, 방향

**문제 2.** `결론·일반화` (옛자료1 8쪽 문제 4)
위도에 따라 중력의 크기가 달라지는 까닭과, 어떻게 달라지는지 적으시오.

**문제 3.** `적용` `의사소통` (옛자료1 8쪽 문제 6)
(**중3 (19) 운동과 에너지**를 공부한 이후) 지구보다 중력의 크기가 2분의 1인 행성에서
축구를 하면 무엇이 어떻게 달라지는지 다섯 가지를 설명하시오.

**문제 4.** `자료 변환·해석` (옛자료1 8쪽 문제 8)
용수철을 잡아당길 때 손과 용수철 사이에 작용하는 힘에 대해 답하시오.

1. 손이 용수철을 잡아당기는 힘과 용수철의 탄성력의 크기를 비교하시오.
2. 벽의 고리와 용수철이 만나는 점에서 작용하는 두 힘의 크기와 방향을 적으시오.
3. 1)·2)에서 구한 힘 중 **용수철에 작용하는 힘만** 고르고 크기와 방향을 적으시오.

**문제 5.** `적용` `결론·일반화` (옛자료1 8쪽 문제 9)
용수철에 매단 물체의 무게에 비례하여 늘어나는 그래프가 있다. 같은 용수철 여러 개가
있을 때 답하시오. (용수철의 무게는 0으로 본다.)

1. 용수철 둘을 위아래로 잇고 맨 아래에 2 kg 추를 달았을 때 위·아래 용수철이 늘어난 길이
2. 용수철 둘을 위아래로 잇고 두 용수철 사이와 맨 아래에 각각 2 kg 추를 달았을 때
3. 용수철 둘을 좌우로 나란히 놓고 무게 없는 판으로 이어 맨 아래에 2 kg 추를 달았을 때

**문제 6.** `개념 이해` `적용` (옛자료1 10쪽 문제 1·2·3·4·6·7)
다음을 적으시오.

1. 마찰력의 뜻, 크기, 방향과 크기를 정하는 요소 두 가지
2. 일상생활에서 마찰력을 크게 하는 예와 작게 하는 예를 각각 세 가지
3. 부력의 뜻, 크기, 방향과 크기를 정하는 요소

**문제 7.** `결론·일반화` `의사소통` (옛자료1 10쪽 문제 5)
「말이 마차를 당기면 마차도 같은 크기의 반대 방향 힘으로 말을 당긴다. 따라서 두 힘을
더하면 0이 되어 말은 마차를 끌 수 없다」는 말의 모순을 찾아 설명하시오.

**문제 8.** `적용` (옛자료1 10쪽 문제 8)
잠수함의 공기 조절 탱크에 물을 채우면 잠수함이 어떻게 되는지 설명하시오.

**문제 9.** `문제 인식·가설` `자료 변환·해석` (옛자료1 10쪽 문제 9)
비커에 물체 A, B 가 각각 부피의 절반만큼 잠긴 채 떠 있다. 이 비커를 30도 빗면에
올려놓았을 때 답하시오.

1. 비커를 빗면에 고정했을 때 중력과 부력의 방향이 어떻게 변하는지 설명하고 물의 표면과
   A, B 를 그리시오.
2. 비커를 고정하지 않고 빗면 오른쪽 면을 왼쪽으로 밀어 빗면째 움직여 비커가 빗면에
   멈춰 있을 때, 중력과 부력의 방향이 어떻게 변하는지 설명하고 물의 표면과 A, B 를
   그리시오.

## 02. 힘과 운동

| | |
|---|---|
| 교재 | `하이탑1-2` 032~041쪽 |
| 옛 자료 | `옛자료3` 18~19쪽 (3단원-01 운동) |

15개정에서 중3 이던 자리다. 22개정에서 중1 로 두 학년 내려왔다. **다만 15개정의
「운동」에는 일과 에너지가 함께 있었는데, 그쪽은 중3 (19) 운동과 에너지에 남는다.**

### 학생들의 추가 학습 목표

1. 시간에 따른 이동 거리 그래프와 속력 그래프를 보고 어떤 운동인지 알 수 있어야
   합니다. 두 그래프를 서로 바꿔 그릴 수 있어야 합니다.

2. 다중 섬광 사진을 분석하여, **정지 상태에서 시작하지 않아도** 물체의 속력이나 위치를
   계산할 수 있어야 합니다.

3. 물체에 작용하는 힘이 속력을 바꾸거나 운동 방향을 바꾸는 원인임을 알고, 힘이 작용할
   때와 작용하지 않을 때의 운동을 나누어 설명할 수 있어야 합니다.
   **이 목표는 옛 자료에서 Ⅴ-01 쪽에 있던 것인데 22개정 차례에 맞춰 이쪽으로 옮겼습니다.**

### 문제

**문제 1.** `자료 변환·해석` `적용` (옛자료3 19쪽 문제 1)
자율주행 자동차에서 공주거리는 카메라가 위험을 알아챈 순간부터 브레이크가 걸릴 때까지
움직인 거리이고, 제동거리는 브레이크가 걸린 순간부터 멈출 때까지 움직인 거리이다.
제동거리는 브레이크가 걸린 순간 속력의 제곱에 비례한다. 3차 테스트에서 자동차가 출발한
지 18초 뒤 카메라가 위험을 알아챘다. 공주거리와 제동거리를 각각 a 에 대한 식으로 적고
과정을 설명하시오.

**문제 2.** `자료 변환·해석` `결론·일반화` (옛자료3 19쪽 문제 2)
0.1초마다 찍는 시간기록계에 기록된 점의 위치가 있다. 물체의 속력이 일정하게 변한다고
할 때 답하시오. (위치는 cm 단위이다.)

1. 속력이 어떻게 변하고 있는지 설명하고, 1초에 속력이 얼마나 변하는지 적으시오.
2. 물체가 정지 상태에서 출발했다면, 기록된 부분은 출발한 지 몇 초 뒤부터의 자료인지
   설명하시오.

**문제 3.** `개념 이해` `자료 변환·해석` (새로)
등속 운동과 속력이 일정하게 변하는 운동을 다음 두 가지 그래프로 각각 그리고, 두 그래프가
서로 어떻게 이어지는지 설명하시오.

1. 시간에 따른 이동 거리 그래프
2. 시간에 따른 속력 그래프

### 교재 서술형 문제

`하이탑1-2` 041쪽. 다른 중단원보다 적다. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.
