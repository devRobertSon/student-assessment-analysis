# 중1 Ⅳ. 물질의 상태 변화

| | |
|---|---|
| 교재 | `하이탑1-1` 128~181쪽 |
| 최상위권 도전 문제 | `하이탑1-1` 170쪽 |
| 논술형 문제 | `하이탑1-1` 174쪽 |
| 옛 자료 | `옛자료1` 20~23쪽 (5단원) · `옛자료1` 15~16쪽 (4단원-01 입자의 운동) |

22개정에서 중단원 이름이 「물질의 상태 변화」에서 **「입자의 운동과 상태 변화」**로
바뀌었다. 15개정에서 기체 단원에 있던 증발과 확산이 이쪽으로 옮겨 왔기 때문이다.
기체의 압력 쪽은 중1 Ⅵ 기체의 성질에 남는다.

## 01. 입자의 운동과 상태 변화

| | |
|---|---|
| 교재 | `하이탑1-1` 130~153쪽 |
| 옛 자료 | `옛자료1` 20~21쪽 + `옛자료1` 15~16쪽 |
| 옮기면서 | `옛자료1` 4단원-01 의 증발·확산을 여기로 가져왔다. 기체의 압력은 **중1 Ⅵ-01 기체의 압력과 부피**에 남겼다 |

### 학생들의 추가 학습 목표

1. 실생활에서 증발과 확산의 예를 최대한 많이 생각해 보고, 각 예에서 증발이나 확산이
   잘 일어나는 조건을 덧붙여 설명할 수 있어야 합니다.

2. 물보다 에탄올이 빨리 증발하는 까닭을 설명할 수 있어야 합니다.

3. **심화:** 풍선에 기체를 넣어 두면 시간이 지나 작아지는 까닭을 분출로 설명할 수
   있어야 합니다. 분출도 확산처럼 온도가 높고 입자의 질량이 작을수록 빠르게 일어나며,
   이 속도 차이로 기체 혼합물을 분리할 수 있음을 생각해 볼 수 있어야 합니다.
   자세한 내용은 **중2 Ⅰ-03 혼합물의 분리**를 수강할 때 설명해도 됩니다.

4. 물중탕으로 가열하여 녹일 수 있는 물질의 특징을 설명할 수 있어야 합니다.

5. **심화:** 물이 얼음보다 부피가 작은 까닭을 물과 얼음의 입자 구조로 설명할 수
   있어야 합니다.

6. **심화:** 드라이아이스 같은 승화성 물질의 승화와, 포화수증기압 차이에 따른 얼음과
   수증기 사이의 승화가 어떻게 다른지 설명할 수 있어야 합니다. 포화수증기압은
   **중3 (17) 날씨와 기후변화**를 수강할 때 설명해도 됩니다.

### 문제

**문제 1.** `개념 이해` (옛자료1 16쪽 문제 1·2)
증발의 뜻과 끓음과의 차이를 적고, 증발이 잘 일어나는 조건을 네 가지 적으시오.

**문제 2.** `결론·일반화` (옛자료1 16쪽 문제 3)
액체의 종류에 따라 증발 속도가 달라지는 까닭을 설명하시오.

**문제 3.** `적용` (옛자료1 16쪽 문제 4)
(**중3 (17) 날씨와 기후변화**를 공부한 이후) 이슬점이 다르고 나머지 환경이 모두 같은
두 공기 안에 물이 담긴 비커가 각각 있다. 어느 비커에서 증발이 잘 일어나는지 설명하시오.

**문제 4.** `개념 이해` `탐구 수행` (옛자료1 16쪽 문제 5·6·7)
확산의 뜻과 생활 속 확산 현상 두 가지를 적고, 확산이 잘 일어나는 조건을 네 가지
적으시오. 또 암모니아 기체의 확산 실험에서 페놀프탈레인 용액으로 적신 솜이 붉게 변하는
까닭을 설명하시오.

**문제 5.** `결론·일반화` (옛자료1 16쪽 문제 8)
같은 양의 물과 소금물에 각각 잉크를 떨어뜨리면 확산 속도가 어떻게 달라지는지 입자의
운동으로 설명하시오.

**문제 6.** `개념 이해` (옛자료1 21쪽 문제 1·2)
물질의 세 가지 상태를 입자 배열의 규칙성, 입자 사이의 거리, 입자 사이의 인력으로
비교하여 설명하시오. 또 상태 변화 여섯 가지를 적고 각각 실생활의 예를 네 가지씩
설명하시오.

**문제 7.** `자료 변환·해석` `결론·일반화` (옛자료1 21쪽 문제 3)
뚜껑이 열린 페트병에 에탄올을 조금 넣고 50 ℃ 물이 담긴 수조에 넣었다가, 액체가
사라지면 꺼내어 뚜껑을 닫는다. 상온에 두면 페트병이 찌그러진다.

1. 찌그러지는 원인을 입자의 운동으로 설명하시오.
2. 페트병이 처음 부피의 3분의 1이 되었다면 안쪽 기압이 어떻게 변했는지 구하시오.

**문제 8.** `자료 변환·해석` `결론·일반화` (옛자료1 21쪽 문제 4)
유리병에 물을 넣고 가열하다가 물이 모두 사라지면 꺼내어 입구에 풍선을 씌운다. 상온에
두면 풍선이 유리병 안에서 팽창한다.

1. 풍선이 유리병 안으로 들어간 까닭을 입자의 운동으로 설명하시오.
2. 풍선의 부피가 유리병 전체의 절반일 때 풍선 안쪽과 바깥쪽의 압력을 각각 대기압의
   몇 배인지 나타내시오.

### 교재 서술형 문제

`하이탑1-1` 152~153쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 02. 상태 변화와 열에너지

| | |
|---|---|
| 교재 | `하이탑1-1` 154~169쪽 |
| 옛 자료 | `옛자료1` 22~23쪽 |

### 학생들의 추가 학습 목표

1. 열에너지의 이동을 포함한 상태 변화 현상의 예를 최대한 많이 생각해 볼 수 있어야
   합니다.

2. **심화:** 외부 압력에 따라 녹는점, 어는점, 끓는점이 어떻게 달라지는지 설명할 수
   있어야 합니다. **물의 녹는점만 다른 물질과 반대로 변하는 까닭**을 물과 얼음의 부피
   관계로 설명할 수 있어야 합니다.

3. 창의 사고력 향상 문제를 통해 실생활의 과학 현상에서 물질의 상태 변화를 설명할 수
   있어야 합니다.

### 문제

**문제 1.** `개념 이해` (옛자료1 23쪽 문제 1·2·3)
열에너지의 크기와 이동 방향을 적으시오. 또 상태 변화가 일어날 때 온도가 일정하게
유지되는 구간의 온도를 가리키는 이름을 적고 그 까닭을 설명하시오. 고체·액체·기체
사이의 상태 변화마다 열에너지를 흡수하는지 방출하는지 적으시오.

**문제 2.** `적용` (옛자료1 23쪽 문제 4·5)
일상생활에서 열에너지를 흡수하는 것을 이용한 예와 방출하는 것을 이용한 예를 각각
다섯 가지씩 적으시오.

**문제 3.** `결론·일반화` `의사소통` (옛자료1 23쪽 문제 6)
차가운 식혜가 든 컵을 들고 건식 사우나에 들어갔더니 ㉠ 컵 표면에 물방울이 생겼다가
얼마 후 ㉡ 물방울이 사라졌다. 시간이 지나면서 ㉢ 피부에 액체 방울이 생겼다. ㉠~㉢이
일어나는 까닭을 각각 설명하시오.

**문제 4.** `탐구 설계` `결론·일반화` (옛자료1 23쪽 문제 7)
항아리 냉장고에 대해 답하시오.

1. 항아리 냉장고의 온도가 바깥보다 낮아지는 까닭을 설명하시오.
2. 두 항아리 사이에 물만 넣는 것보다 젖은 모래를 넣었을 때 온도가 더 내려가는 까닭을
   설명하시오.
3. 냉장 효과를 높일 수 있는 날씨 조건을 세 가지 적으시오.

### 교재 서술형 문제

`하이탑1-1` 168~169쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.
