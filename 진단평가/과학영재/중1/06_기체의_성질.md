| | |
|---|---|
| 교재 | `하이탑1-2` 054~095쪽 |
| 최상위권 도전 문제 | `하이탑1-2` 084쪽 |
| 논술형 문제 | `하이탑1-2` 088쪽 |
| 옛 자료 | `옛자료1` 15~19쪽 (4단원 기체의 성질) |

15개정에서는 01 입자의 운동 · 02 기체의 부피 변화였는데, 22개정에서 **01 기체의
압력과 부피 · 02 기체의 온도와 부피**로 다시 나뉘었다. 증발과 확산은 여기서 빠져
**중1 Ⅳ-01 입자의 운동과 상태 변화**로 갔다.

## 01. 기체의 압력과 부피

| | |
|---|---|
| 교재 | `하이탑1-2` 056~071쪽 |
| 옛 자료 | `옛자료1` 17~19쪽 중 압력과 보일 법칙 부분 |
| 옮기면서 | `옛자료1` 15~16쪽(입자의 운동)의 증발·확산은 **중1 Ⅳ-01** 로 보냈다 |

### 학생들의 추가 학습 목표

1. **압력은 면에 수직으로 작용하는 힘에 비례하지만 힘은 아니라는 점**을 정확히 알고
   있어야 합니다. 같은 힘이라도 닿는 면적이 달라지면 압력이 달라집니다.

2. 보일 법칙이 성립하는 조건이 **온도가 일정할 때**라는 것을 알고 있어야 합니다.

3. 실생활에서 보일 법칙과 관련된 현상의 예를 최대한 많이 생각해 볼 수 있어야 합니다.

4. **심화 & 집중분석:** 기체의 온도, 압력, 부피가 함께 변해도 보일·샤를 법칙이 성립함을
   알고 계산 문제에 쓸 수 있어야 합니다. 또 이 법칙은 **기체의 입자 수가 변하지 않을
   때에만** 성립함을 알고 있어야 합니다.

5. 창의 사고력 향상 문제를 통해 실생활의 과학 현상을 기체 입자의 운동과 성질로 설명할
   수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` `적용` (옛자료1 18쪽 문제 1·2·3)
압력의 뜻을 적으시오. 또 일상생활에서 압력을 크게 만드는 예와 작게 만드는 예를 각각
두 가지씩 적고, 기체의 압력이 작용하는 방향과 기체의 압력이 커지는 요인 세 가지를
설명하시오.

**문제 2.** `개념 이해` `결론·일반화` (옛자료1 18쪽 문제 4)
기체에 가하는 압력과 기체의 부피 사이 관계를 나타내는 법칙과 그 법칙이 성립하기 위한
조건을 적으시오. 또 이 법칙을 기체 입자의 운동으로 설명하시오.

**문제 3.** `적용` (옛자료1 18쪽 문제 6)
(**중3 (17) 날씨와 기후변화**를 공부한 이후) 토리첼리가 기압을 잴 때 물이 아니라 수은을
쓴 까닭을 설명하시오.

**문제 4.** `자료 변환·해석` `적용` (옛자료1 18쪽 문제 7)
비행기가 이륙하면 고도가 높아질수록 바깥 대기압이 낮아진다. 풍선을 비행기 안에
가져갔을 때 답하시오.

1. 풍선의 크기가 4분 동안 변하고 이후 그대로 유지되었다. 4분 동안 어떻게 변했는지 적고
   까닭을 설명하시오. 또 그래프에 풍선 안쪽의 압력 변화를 그리시오.
2. 비행기 안에서 250 mL 유리병의 뚜껑을 오래 열어 두었다가 닫았다. 집에 돌아와 물이
   담긴 그릇에 거꾸로 세우고 뚜껑을 열었더니 50 mL 의 물이 빨려 들어갔다. 비행기가
   이륙한 다음 비행기 안쪽 기압은 몇 기압인지 구하시오.
3. (**중3 (20) 자극과 반응**을 공부한 이후) 비행기가 이륙할 때 귀가 먹먹해지는 까닭을
   설명하고, 그때 고막이 어느 쪽으로 부풀어 오르는지, 어떻게 하면 풀리는지 설명하시오.

**문제 5.** `적용` `결론·일반화` (옛자료1 19쪽 문제 8)
같은 부피의 기체가 든 정육면체 구역 A~E 가 있다. A-B 사이와 B-C 사이는 좌우로 움직이는
슬라이드 막이고, C-D 사이와 B-E 사이는 기체가 오갈 수 있는 연결관이다. D 의 윗면과
E 의 아랫면에는 피스톤이 있다. 두 피스톤을 움직여 D 의 부피를 처음의 5분의 3, E 의
부피를 처음의 5분의 2로 만들면 슬라이드 막이 움직인다.

1. 막이 움직이기 전 A 의 압력을 P 라 할 때 움직인 뒤 A 의 압력을 P 로 나타내시오.
2. 막이 움직인 뒤 A, B, C 단면의 너비 비를 구하시오.

## 02. 기체의 온도와 부피

| | |
|---|---|
| 교재 | `하이탑1-2` 072~083쪽 |
| 옛 자료 | `옛자료1` 17~18쪽 중 샤를 법칙 부분 |

### 학생들의 추가 학습 목표

1. 샤를 법칙이 성립하는 조건이 **압력이 일정할 때**라는 것을 알고 있어야 합니다.

2. 실생활에서 샤를 법칙과 관련된 현상의 예를 최대한 많이 생각해 볼 수 있어야 합니다.

3. **심화:** 샤를 법칙에서 기체의 온도와 부피는 **정비례가 아니라 비례**입니다. 정비례가
   되려면 온도가 섭씨온도가 아니라 절대온도여야 함을 생각해 볼 수 있어야 합니다.
   그래프를 왼쪽으로 늘였을 때 −273 ℃ 에서 부피가 0이 되는 것이 그 근거입니다.

### 문제

**문제 1.** `개념 이해` `결론·일반화` (옛자료1 18쪽 문제 5)
온도와 기체의 부피 사이 관계를 나타내는 법칙과 그 법칙이 성립하기 위한 조건을 적으시오.
또 이 법칙을 기체 입자의 운동으로 설명하시오.

**문제 2.** `적용` `의사소통` (옛자료1 19쪽 문제 9)
뚜껑이 꽉 닫힌 유리 잼병을 냉장고에서 꺼낸 다음 바로 열려고 하면 잘 열리지 않는다.

1. 잘 열리지 않는 까닭을 설명하시오.
2. 뚜껑에 고무줄을 감거나 고무장갑을 끼고 여는 방법의 원리를 설명하시오.
3. 숟가락으로 뚜껑 가장자리를 두드린 다음 여는 방법의 원리를 설명하시오.
4. 뚜껑 가장자리 아래에 숟가락을 지렛대처럼 넣어 누른 다음 여는 방법의 원리를 설명하시오.
5. 병의 유리 부분을 뜨거운 천으로 감싸고 얼마 뒤 여는 방법의 원리를 설명하시오.
6. (**중1 Ⅲ-02 비열과 열팽창**을 공부한 이후) 뚜껑에 따뜻한 물을 흘리거나 담갔다
   꺼내어 여는 방법의 원리를 설명하시오.

**문제 3.** `자료 변환·해석` `결론·일반화` (새로)
압력이 일정할 때 기체의 온도와 부피를 잰 그래프를 왼쪽으로 늘이면 −273 ℃ 에서 부피가
0이 된다. 실제 기체의 부피가 0이 될 수 없는데도 이 점이 뜻을 가지는 까닭을 설명하고,
이 온도를 0으로 삼는 온도 눈금의 이름을 적으시오.

### 교재 서술형 문제

`하이탑1-2` 083쪽. 다른 중단원보다 적다. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.
