# 중2 Ⅰ. 물질의 특성

| | |
|---|---|
| 교재 | `하이탑2-1` 010~073쪽 |
| 최상위권 도전 문제 | `하이탑2-1` 062쪽 |
| 논술형 문제 | `하이탑2-1` 066쪽 |
| 옛 자료 | `옛자료2` 32~40쪽 (6단원 물질의 특성) |

15개정 중2 의 6단원이 22개정 중2 의 맨 앞 단원이 되었다. **중단원 셋의 이름과 차례가
그대로다.** 학년도 그대로라 옮기는 일이 거의 없는 단원이다.

---

## 01. 물질의 특성 (1)

| | |
|---|---|
| 교재 | `하이탑2-1` 012~027쪽 |
| 옛 자료 | `옛자료2` 32~34쪽 |

### 학생들의 추가 학습 목표

1. 순물질을 섞어 쓰는 경우가 주어지면 **왜 섞어 쓰는지** 설명할 수 있어야 합니다.
   합금, 부동액, 퓨즈처럼 섞어서 새 성질을 얻는 예를 모아 두어야 합니다.

2. 밀도가 클수록 부력의 크기가 커지는 것을 부력의 크기로 설명할 수 있어야 합니다.
   이 목표는 **중1 Ⅴ-01 여러 가지 힘**에서 배운 아르키메데스의 원리와 이어집니다.

3. **탐구:** 여러 물질을 밀도, 녹는점, 끓는점, 용해도 같은 특성으로 차례차례 갈라
   분류표를 완성할 수 있어야 합니다. 한 번 쓴 기준은 다시 쓰지 않는 것이 규칙입니다.

### 문제

**문제 1.** `개념 이해` (옛자료2 33쪽 문제 1)
균일 혼합물과 불균일 혼합물의 예를 각각 세 가지씩 적으시오.

**문제 2.** `적용` `결론·일반화` (옛자료2 33쪽 문제 2)
다음은 순물질을 섞어 쓰는 예이다. 각 예에서 섞는 까닭을 적으시오.

1. 철과 크로뮴을 섞어 스테인리스 합금을 만든다.
2. 물에 에틸렌 글리콜을 섞어 자동차 부동액을 만든다.
3. 납과 주석을 섞어 퓨즈를 만든다.

**문제 3.** `결론·일반화` (옛자료2 33쪽 문제 3)
물에 다음 물질을 넣으면 하나는 떠오르고 다른 하나는 가라앉는다. 까닭을 설명하시오.

1. 크기가 같지만 질량이 다른 500 g 쇠공과 50 g 스티로폼공
2. 질량이 같지만 크기가 다른 지름 5 cm 쇠공과 지름 50 cm 스티로폼공

**문제 4.** `탐구 설계` `자료 변환·해석` (옛자료2 34쪽 문제 4)
여덟 가지 물질을 분류하는 과정이 있다.

1. 분류 기준 (1)~(7)을 적으시오. (한 번 쓴 기준은 다시 쓸 수 없다.)
2. 물질 A~F 를 적으시오.

### 교재 서술형 문제

`하이탑2-1` 026~027쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 02. 물질의 특성 (2)

| | |
|---|---|
| 교재 | `하이탑2-1` 028~043쪽 |
| 옛 자료 | `옛자료2` 35~37쪽 |

### 학생들의 추가 학습 목표

1. 균일 혼합물인 **용액의 특징**을 설명할 수 있어야 합니다.

2. **심화:** 용질이 고체인 용액과 기체인 용액에서 용해도가 달라지는 요인을 각각 설명할
   수 있어야 합니다. **고체는 온도만, 기체는 온도와 압력 둘 다**가 핵심입니다.

3. **탐구:** 용해도 곡선을 읽어 어느 온도에서 몇 g 이 석출되는지 구할 수 있어야 합니다.
   「처음 녹아 있던 양 − 냉각한 온도에서 최대로 녹는 양」이 석출량입니다.

### 문제

**문제 1.** `개념 이해` (옛자료2 36쪽 문제 1)
용액의 특징을 있는 대로 적으시오.

**문제 2.** `결론·일반화` (옛자료2 36쪽 문제 2)
용액에서 기체의 용해도와 온도 사이 관계가 비례인지 반비례인지 적고, 그 까닭을 입자의
운동으로 설명하시오.

**문제 3.** `문제 인식·가설` `결론·일반화` (옛자료2 36쪽 문제 3)
비커 A 와 B 에 서로 다른 액체를 각각 1 L 씩 준비해 비커 C 에 모두 넣고 섞는다. 두
액체가 화학 반응을 하지 않는다고 할 때 답하시오.

1. C 에서 부피가 2 L 가 되었다. 까닭을 설명하시오.
2. C 에서 부피가 1.9 L 가 되었다. 까닭을 설명하시오.

**문제 4.** `자료 변환·해석` `탐구 설계` (옛자료2 37쪽 문제 4)
액체 A 100 g 과 B 40 g 을 눈금 실린더에 넣고 흔든 뒤 두었더니 두 층으로 나뉘었고
부피비는 위층 : 아래층 = 1 : 2 였다. 여기에 액체 C 를 더 넣고 흔들었더니 다시 두 층이
되었고 부피비가 같았다. 한 층은 순물질이고 다른 한 층은 두 액체의 혼합물이다.

1. A 와 B 중 밀도가 큰 것을 고르고 까닭을 적으시오.
2. 부피비가 그대로라는 결과를 설명할 수 있는 C 의 성질 두 가지를 적으시오.
3. 이 액체를 단계별로 분리할 때 각 단계에서 이용하는 물질의 특성과 방법을 설명하시오.

## 03. 혼합물의 분리

| | |
|---|---|
| 교재 | `하이탑2-1` 044~061쪽 |
| 옛 자료 | `옛자료2` 38~40쪽 |

### 학생들의 추가 학습 목표

1. 혼합물을 분리할 때 이용하는 물질의 특성과 방법의 이름을 알고 있고, **각 방법을 쓴
   실험을 직접 설계할 수 있어야 합니다.**

2. **심화:** 기체 혼합물을 분출 속도 차이로 분리할 수 있음을 알아야 합니다. 이 내용은
   **중1 Ⅳ-01 입자의 운동과 상태 변화**에서 미리 짚어 둔 것입니다.

### 문제

**문제 1.** `개념 이해` `탐구 설계` (옛자료2 39쪽 문제 1)
혼합물을 분리하는 데 쓰는 **물질의 특성 다섯 가지**를 적고, 각 특성을 이용한 대표적인
분리 방법을 하나씩 적고 실험 방법을 간단히 적으시오.

**문제 2.** `개념 이해` (옛자료2 39쪽 문제 2)
혼합물 분리 방법 중 거름과 추출의 차이를 설명하시오.

**문제 3.** `탐구 수행` `자료 변환·해석` (옛자료2 40쪽 문제 3)
비커 안에 여러 물질이 섞여 있다.

1. (가)와 (라)의 실험 방법과 필요한 실험 기구를 적으시오.
2. (마)에서 얻을 수 있는 순수한 질산 칼륨의 최대 질량을 구하시오. (손실은 없다.)

### 교재 서술형 문제
