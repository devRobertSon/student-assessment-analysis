# 중2 Ⅲ. 빛과 파동

| | |
|---|---|
| 교재 | `하이탑2-1` 132~181쪽 |
| 최상위권 도전 문제 | `하이탑2-1` 170쪽 |

| 옛 자료 | `옛자료1` 24~29쪽 (6단원 빛과 파동) |

15개정 중1 의 마지막 단원이 중2 로 올라왔다. 중단원이 **셋에서 둘로 줄었다.**
빛과 색, 거울과 렌즈가 한 중단원 「빛」으로 합쳐졌다.

## 01. 빛

| | |
|---|---|
| 교재 | `하이탑2-1` 134~153쪽 |
| 옛 자료 | `옛자료1` 24~25쪽 (빛과 색) · `옛자료1` 26~27쪽 (거울과 렌즈) |

15개정 중단원 **둘이 하나로 합쳐졌다.** 옛 자료의 분량이 많아 문제가 가장 많이 모인다.

### 학생들의 추가 학습 목표

1. 바늘구멍 사진기로 물체를 보면 어떻게 보이는지 설명할 수 있어야 합니다.

2. 조명의 색을 볼 때, 불투명한 물체의 색을 볼 때, 투명한 물체의 색을 볼 때를 **나누어**
   설명할 수 있어야 합니다. 셋은 보이는 원리가 서로 다릅니다.

3. 백색광이 프리즘을 지날 때 굴절이 일어나고, 굴절이 많이 일어날수록 작은 입자와 부딪혀
   사방으로 흩어지는 산란이 잘 일어남을 알고 있어야 합니다.

4. **심화:** 빨강과 초록 반응 세포가 함께 반응하면 노란색으로, 초록과 파랑이 함께
   반응하면 청록색으로 느낍니다. 그렇다면 빨강과 파랑이 함께 반응할 때 왜 자홍색으로
   느끼는지 대뇌의 합성 방식을 생각해 볼 수 있어야 합니다.

5. **난반사에서도 반사 법칙이 성립함**을 정확히 알고 있어야 합니다. 면이 울퉁불퉁해서
   법선의 방향이 제각각일 뿐입니다.

6. 거울에 의한 상은 거울의 종류와 관계없이 모두 좌우가 바뀐 모습임을 알고 있어야 합니다.

7. **심화:** 거울과 렌즈에 의한 상이 어디에 생기는지 작도할 수 있어야 합니다.

8. 평면거울 두 개 사이에 놓인 물체의 상이 몇 개 생기는지, 두 거울 사이의 각도에 따라
   어떻게 변하는지 생각해 볼 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` (옛자료1 25쪽 문제 1·2·3)
광원이 아닌 물체를 보는 원리를 설명하고, 물체에 그림자가 생기는 원리를 설명하시오.
또 바늘구멍 사진기의 원리와 바늘구멍을 지난 물체가 눈에 어떻게 보이는지 적으시오.

**문제 2.** `개념 이해` `적용` (옛자료1 25쪽 문제 4·5)
빛의 3원색과 이 빛들이 합성되어 만들어지는 빛을 모두 구하시오. 또 불투명한 물체의 색과
투명한 물체의 색이 각각 어떤 원리로 보이는 색인지 설명하시오.

**문제 3.** `결론·일반화` (옛자료1 25쪽 문제 6)
붉은색 조명이 있는 유령의 집에서 손에 든 풍선이 검게 보였다. 백색광에서 이 풍선이 어떤
색으로 보일지 세 가지를 구하시오.

**문제 4.** `적용` `결론·일반화` (옛자료1 25쪽 문제 7)
낮에 하늘이 파랗게 보이는 까닭과 해 질 때 노을이 붉게 보이는 까닭을 설명하시오.

**문제 5.** `탐구 수행` `자료 변환·해석` (옛자료1 25쪽 문제 8)
백색 광원 앞에 노란색 셀로판지를, 센서 앞에 빨강·초록·파랑 셀로판지를 바꿔 끼우며 빛의
양을 잰 실험이 있다. ㉢은 어떤 색깔의 셀로판지인지 설명하시오.

**문제 6.** `개념 이해` `자료 변환·해석` (옛자료1 27쪽 문제 1·2·3)
반사의 법칙을 설명하고 난반사에서도 성립하는지 적으시오. 또 평면거울·볼록거울·오목거울
앞의 물체가 거울에서 멀어질 때 생기는 상의 위치·모습·크기를 설명하고, 볼록거울과
오목거울을 이용한 예를 각각 세 가지씩 찾아 적으시오.

**문제 7.** `개념 이해` `자료 변환·해석` (옛자료1 27쪽 문제 4·5)
빛의 굴절이 어디에서 일어나는지 설명하고 굴절에 의한 현상 세 가지를 적으시오. 또
볼록렌즈와 오목렌즈 앞의 물체가 렌즈에서 멀어질 때 생기는 상의 위치·모습·크기를
설명하시오.

**문제 8.** `문제 인식·가설` `결론·일반화` (옛자료1 27쪽 문제 6)
공기 중에서 물체를 뚜렷하게 볼 수 있었다. 물속에서 같은 거리의 물체를 뚜렷하게 보려면
어떤 렌즈를 써야 하는지 까닭과 함께 설명하시오.

**문제 9.** `자료 변환·해석` (옛자료1 27쪽 문제 7)
초점거리 3 cm 인 볼록렌즈와 초점거리 3 cm 인 오목거울을 6 cm 간격으로 놓고, 볼록렌즈
왼쪽 3 cm 에서 레이저를 비스듬히 비춘다. 굴절과 반사를 거치는 전체 진행 경로를 그림에
나타내시오.

**문제 10.** `적용` `결론·일반화` (옛자료1 27쪽 문제 8)
물 위에 떠 있는 소금쟁이가 물 바닥에 만든 그림자 ⓐ 와 ⓑ 에 대해 답하시오.

1. 그림자가 생기는 까닭을 빛의 성질과 엮어 설명하시오.
2. ⓐ 는 몸통과 비슷한 크기인데 ⓑ 는 다리 끝보다 훨씬 크게 보이는 까닭을 빛의 성질과
   엮어 설명하시오.

**문제 11.** `결론·일반화` (옛자료1 27쪽 문제 9)
두 평면거울이 직각으로 놓인 곳에 물체가 있다. 이 물체의 상이 몇 개 생기는지 적고 까닭을
설명하시오.

## 02. 파동

| | |
|---|---|
| 교재 | `하이탑2-1` 154~169쪽 |
| 옛 자료 | `옛자료1` 28~29쪽 (파동과 소리) |

### 학생들의 추가 학습 목표

1. **심화:** 횡파를 두 가지 방법으로 그래프로 나타내고, 각 그래프에서 알 수 있는 파동의
   성질을 설명할 수 있어야 합니다.
   1) 특정 시간에서 거리가 달라질 때 파동의 위치를 표시하는 방법
   2) 파동의 한 점에서 시간이 지날 때 위치의 변화를 표시하는 방법

2. **심화:** 종파에서 매질의 진동 방향 중 파동의 진행 방향과 같은 쪽을 + 로 잡아,
   횡파처럼 그래프로 나타내고 설명할 수 있어야 합니다.

3. 파면이 **파동의 같은 위치와 운동 방향을 가진 점들을 이은 면**임을 알고, 파동의 진행
   방향과 항상 수직임을 알고 있어야 합니다.

4. 내가 듣는 내 목소리와 녹음해서 듣는 내 목소리가 다른 까닭을 설명할 수 있어야 합니다.
   귀에서 소리를 듣는 과정은 **중3 (20) 자극과 반응**을 수강할 때 설명해도 됩니다.

### 문제

**문제 1.** `개념 이해` (옛자료1 29쪽 문제 1·2·3)
매질이 무엇인지 설명하고 매질이 필요 없는 파동이 무엇인지 구하시오. 또 횡파와 종파의
차이점을 설명하고 지진파의 P파와 S파가 어떤 파인지 적으시오. 소리의 3요소가 무엇이고
파동의 어느 성질과 관계가 있는지 적으시오.

**문제 2.** `자료 변환·해석` `결론·일반화` (옛자료1 29쪽 문제 4)
움직이는 음원에 대해 답하시오.

1. 주어진 자료에서 x 를 구하고, 두 길이가 같다는 것을 이용하여 듣는 사람이 듣는 진동수를
   구하시오.
2. 가까워지는 앰뷸런스의 사이렌 소리가 멈춰 있을 때와 어떻게 다른지 1)의 결과와 소리의
   3요소를 들어 적으시오.
