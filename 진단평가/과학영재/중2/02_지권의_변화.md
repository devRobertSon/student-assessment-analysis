# 중2 Ⅱ. 지권의 변화

| | |
|---|---|
| 교재 | `하이탑2-1` 074~131쪽 |
| 최상위권 도전 문제 | `하이탑2-1` 120쪽 |
| 논술형 문제 | `하이탑2-1` 124쪽 |
| 옛 자료 | `옛자료1` 1~6쪽 (1단원 지권의 변화) |

15개정 중1 의 맨 앞 단원이 중2 로 올라왔다. 중단원 셋의 내용은 그대로인데 **이름이
모두 바뀌었다.**

| 15개정 | 22개정 |
|---|---|
| 01 지구계와 지구 내부 구조 | 01 지권의 구조 |
| 02 암석과 광물 | 02 지각의 구성 물질 |
| 03 변화하는 지권 | 03 지권의 이동 |

**풍화와 토양은 Ⅱ-02 에 있다.** 교재 104~105쪽 서술형 문제에서 확인했다. 이름만 보면
Ⅱ-03 「지권의 이동」에 갈 것 같지만 아니다.

## 01. 지권의 구조

| | |
|---|---|
| 교재 | `하이탑2-1` 076~085쪽 |
| 옛 자료 | `옛자료1` 1~2쪽 |

### 학생들의 추가 학습 목표

1. 지구계를 이루는 각 구성 요소 사이의 상호작용에 해당하는 자연 현상을 최대한 많이
   설명할 수 있어야 합니다. 실생활의 과학 현상을 **지구계 구성 요소 사이의 상호작용으로
   바꿔 생각해 볼 수 있어야** 합니다.

2. **탐구:** 지구 내부 구조 모형을 만들 때, 각 층의 두께 차이보다 부피 차이가 훨씬
   큰 까닭을 생각해 보고 직접 계산해 볼 수 있어야 합니다.

3. **심화:** 지진파의 P파와 S파가 어떻게 다른지, 그래서 S파가 닿지 못하는 부분이 생기는
   까닭을 생각해 볼 수 있어야 합니다. 자세한 내용은 **중2 Ⅲ-02 파동**을 수강할 때
   설명해도 됩니다.

4. **심화:** 지진파가 구성 물질이 달라지는 경계면에서 속도가 달라지는 까닭을 생각해 볼 수
   있고, 그래서 경계면을 지날 때 어느 방향으로 꺾이는지 생각해 볼 수 있어야 합니다.
   자세한 내용은 **중2 Ⅲ-01 빛**을 수강할 때 설명해도 됩니다.

5. **심화:** 지진파가 같은 층 안에서도 속도가 달라지는 까닭을 생각해 볼 수 있고, 그래서
   지구 내부를 지날 때 각 층 안에서 어느 방향으로 휘는지 생각해 볼 수 있어야 합니다.

### 문제

**문제 1.** `적용` `의사소통` (옛자료1 2쪽 문제 1)
지구계의 다섯 구성 요소 사이의 열 가지 상호작용을 각각 한 가지씩 설명하시오.
(중등 과학 전체를 공부한 뒤에는 각각 세 가지씩 설명하시오.)

**문제 2.** `개념 이해` (옛자료1 2쪽 문제 2)
(**중2 Ⅲ-02 파동**을 공부한 이후) 횡파와 종파의 차이점을 설명하고 지진파의 P파와
S파가 어떤 파에 해당하는지 적으시오.

**문제 3.** `적용` `결론·일반화` (옛자료1 2쪽 문제 3)
(**중1 수학 평면도형과 입체도형**을 공부한 이후) 지구 반지름이 6400 km 일 때 맨틀,
외핵, 내핵이 각각 지구 전체 부피의 몇 %를 차지하는지 계산하시오. (지각의 두께는 다른
층에 비해 매우 얇으므로 0으로 본다.)

**문제 4.** `자료 변환·해석` `결론·일반화` (옛자료1 2쪽 문제 4)
지진파에 대해 답하시오.

1. 지진파가 관측되지 않는 부분이 생기는 까닭과 P파만 닿는 부분이 생기는 까닭을 각각
   적으시오.
2. (**중2 Ⅲ-01 빛**을 공부한 이후) 지진파가 지구 중심 쪽이 아니라 바깥쪽으로 굴절되는
   까닭을 설명하시오.
3. (**중2 Ⅲ-01 빛**을 공부한 이후) 외핵의 부피가 지금보다 커진다면 지진파가 관측되지
   않는 부분이 어떻게 변할지 예상하고 까닭을 설명하시오.

### 교재 서술형 문제

`하이탑2-1` 085쪽. 다른 중단원보다 적다. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 02. 지각의 구성 물질

| | |
|---|---|
| 교재 | `하이탑2-1` 086~105쪽 |
| 옛 자료 | `옛자료1` 3~4쪽 (암석과 광물) |

### 학생들의 추가 학습 목표

1. 광물과 암석, 마그마와 용암, 층리와 엽리와 편리, 풍화와 침식처럼 **비슷한 뜻으로 쓰는
   개념을 확실하게 구분하여** 설명할 수 있어야 합니다.

2. 암석의 세 종류와 생성 과정, 암석의 순환을 논리적으로 생각할 수 있어 **책을 보지 않고도**
   설명할 수 있어야 합니다.

3. 광물인 방해석과, 방해석으로 이루어진 암석인 석회암·대리암을 구분할 수 있고 모두 염산
   반응이 일어남을 알아야 합니다. 또 그 거품이 물과 이산화 탄소로 이루어짐을 알아야
   합니다. 탄산 칼슘의 염산 반응은 **중3 (16) 화학 반응의 규칙성**을 수강할 때 설명해도
   됩니다.

4. **탐구:** 화성암을 구분하는 두 기준에 따라 화성암 네 가지를 구분할 수 있어야 합니다.

5. **탐구 & 심화:** 광물이나 암석 다섯 가지를 골라 예·아니요로 가를 수 있는 기준 네 개를
   넣어 분류하는 연습을 통해, 분류 기준을 완성된 문장으로 쓰는 연습을 할 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` (옛자료1 4쪽 문제 1·2·3)
광물과 암석의 차이, 마그마와 용암의 차이를 적으시오. 또 암석을 분류하는 기준과 그
기준으로 나뉜 암석 세 가지를 적고, 화성암·퇴적암·변성암의 생성 과정을 설명하시오.

**문제 2.** `개념 이해` `자료 변환·해석` (옛자료1 4쪽 문제 4·5)
화성암을 분류하는 기준 두 가지와 그 두 기준으로 나뉜 화성암 네 가지를 적으시오. 또
화성암 중 구성 광물의 결정 크기가 큰 암석을 적고 결정이 큰 까닭을 설명하시오.

**문제 3.** `탐구 설계` `문제 인식·가설` (옛자료1 4쪽 문제 6)
광물 결정의 크기에 영향을 주는 요인을 찾기 위한 실험을 설계하고 예상되는 결과를 적으시오.

**문제 4.** `자료 변환·해석` (옛자료1 4쪽 문제 7)
암석의 순환 과정을 그려 보시오.

**문제 5.** `개념 이해` (옛자료1 4쪽 문제 8·10·11)
광물의 특성 다섯 가지를 적고 각 특성의 뜻을 적으시오. 또 조암 광물의 뜻을 설명하고,
풍화를 분류하는 기준과 그 기준으로 나뉜 풍화 두 가지를 설명하시오.

**문제 6.** `적용` `결론·일반화` (옛자료1 4쪽 문제 9)
염산에 반응하는 광물의 이름을 적고 이 광물로 주로 이루어진 암석을 적으시오.
(**중3 (16) 화학 반응의 규칙성**을 공부한 이후) 그 광물이 염산에 반응하는 화학 반응식을
적으시오.

**문제 7.** `탐구 설계` `의사소통` (옛자료1 4쪽 문제 12)
다음 광물들을 광물의 특성을 한 가지씩 써서 분류하시오.

> 석영, 방해석, 자철석, 흑운모, 활석, 적철석

## 03. 지권의 이동

| | |
|---|---|
| 교재 | `하이탑2-1` 106~119쪽 |
| 옛 자료 | `옛자료1` 5~6쪽 (변화하는 지권) |

### 학생들의 추가 학습 목표

1. 진원과 진앙, 진도와 규모처럼 비슷한 뜻으로 쓰는 개념을 확실하게 구분하여 설명할 수
   있어야 합니다.

2. 베게너의 대륙 이동설이 기존 이론과 어떻게 달랐는지, 대륙 이동설의 증거는 무엇인지,
   한계는 무엇인지 각각 설명할 수 있어야 합니다. **한계까지 말해야 판 구조론으로 넘어가는
   까닭이 드러납니다.**

3. 판의 경계에서 화산 활동과 지진이 자주 일어나는 까닭을 판의 이동 방향과 속력으로
   설명할 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` `결론·일반화` (옛자료1 6쪽 문제 1)
대륙 이동설을 주장한 과학자의 이름과 대륙 이동설의 증거 네 가지를 적고, 대륙 이동설이
기존 가설들과 다른 점과 한계를 설명하시오.

**문제 2.** `개념 이해` (옛자료1 6쪽 문제 2·3)
진원과 진앙의 차이를 적고, 지진의 진도와 규모의 차이를 적으시오.

**문제 3.** `개념 이해` `자료 변환·해석` (옛자료1 6쪽 문제 4)
판의 뜻을 적고, 판을 분류하는 기준과 그 기준으로 나뉜 판 두 종류의 차이점을 세 가지
이상 적으시오.

### 교재 서술형 문제

`하이탑2-1` 118~119쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 옮기면서 한 일

**중단원 이름이 모두 바뀌었다.** 내용은 그대로 이어지므로 자리만 옮겼다.

**고친 참조**

| 옛 표기 | 새 표기 |
|---|---|
| 하이탑 중등과학1의 6단원 빛과 파동 – 03. 파동과 소리 | 중2 Ⅲ-02 파동 |
| 하이탑 중등과학1의 6단원 빛과 파동 – 02. 거울과 렌즈 | 중2 Ⅲ-01 빛 |
| 하이탑 중등과학3의 1단원 화학 반응의 규칙과 에너지 변화 – 02. 화학 반응의 규칙 | 중3 (16) 화학 반응의 규칙성 |
| 중등수학1 평면도형과 입체도형 | 중1 수학 평면도형과 입체도형 |

**빛과 파동 참조가 같은 학년 안으로 들어왔다.** 15개정에서는 중1 학생이 같은 해 뒤쪽
단원을 가리키던 것인데, 22개정에서는 이 단원과 빛과 파동이 **둘 다 중2 이고 Ⅲ 이
Ⅱ 바로 다음**이라 차례가 더 가까워졌다.

**확인한 것**

교재 104~105쪽을 보고 **풍화와 토양이 Ⅱ-02 지각의 구성 물질에 있음**을 확인했다.
`_목차_대조표.md` 에 적어 두었던 의문 하나가 풀렸다.
