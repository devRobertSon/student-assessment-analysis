## 01. 소화와 순환

| | |
|---|---|
| 교재 | `하이탑2-2` 046~067쪽 |
| 옛 자료 | `옛자료2` 28~29쪽 + `옛자료2` 26~27쪽의 영양소 부분 |
| 받아 온 것 | `옛자료2` 27쪽 문제 3 (영양소 검출 반응). 중1 Ⅱ-01 에서 이쪽으로 보냈다 |

### 학생들의 추가 학습 목표

1. **영양소 검출 반응에서 검출 시약의 원래 색까지** 알고 있어야 합니다. 반응 후 색만
   외우면 실험 결과를 읽을 수 없습니다.

2. 소장의 융털처럼 **표면적을 늘려 물질 교환 효율을 높인 구조**의 예를 더 찾아 설명할
   수 있어야 합니다.

3. 심장의 구조와 판막의 자리를 알고 있고, 심장이 한 번 뛸 때 심방과 심실의 수축·이완,
   판막의 열림·닫힘, 압력 변화를 설명할 수 있어야 합니다.

4. **심화:** 소화 효소가 반응에 직접 참여해 생성물이 되는 반응물이 아니라, **활성화
   에너지를 낮춰 주는 촉매**임을 설명할 수 있어야 합니다.

5. **심화:** pH 에 따라 반응 속도가 다른 효소의 종류를, 소화 기관마다 달라지는 pH 로
   설명할 수 있어야 합니다.

### 문제

**문제 1.** `탐구 수행` `자료 변환·해석` (옛자료2 27쪽 문제 3)
다음 음식물에 든 영양소를 검출하기 위한 1) 검출 반응의 종류, 2) 검출 시약의 원래 색과
반응 후 변한 색, 3) 음식물에 든 영양소를 각각 적으시오.

1. 미음
2. 양파즙
3. 달걀흰자 (많이 든 영양소 1개)
4. 달걀노른자 (많이 든 영양소 2개)
5. 식용유

**문제 2.** `개념 이해` (옛자료2 29쪽 문제 1·2)
기계적 소화의 세 가지(저작 운동, 분절 운동, 꿈틀 운동)의 뜻을 각각 적으시오. 또 소화
과정에서 쓸개즙과 다른 소화 효소의 차이를 설명하시오.

**문제 3.** `적용` `결론·일반화` (옛자료2 29쪽 문제 3)
소장의 융털, 온몸의 모세혈관처럼 물질 교환 효율을 늘린 구조를 두 가지 더 적으시오.

**문제 4.** `자료 변환·해석` `결론·일반화` (옛자료2 29쪽 문제 4)
심장이 한 번 뛸 때 다음 과정을 거친다. 각 과정 또는 그 사이에서 1) 심방과 심실의 수축·이완
여부, 2) 판막의 열림·닫힘 여부, 3) 심방과 심실의 압력 변화 그래프를 적으시오.

> 심방·심실 이완 → 심실 수축 → 심방 수축 → (심방·심실 이완)

## 02. 호흡과 배설

| | |
|---|---|
| 교재 | `하이탑2-2` 068~087쪽 |
| 옛 자료 | `옛자료2` 30~31쪽 |

### 학생들의 추가 학습 목표

1. **심화:** 폐의 구조와 숨 쉴 때 각 구조의 이동 방향을 알고 있고, 한 번 호흡할 때 각
   기관의 움직임과 **흉강·폐 안쪽의 압력 변화**를 설명할 수 있어야 합니다.

2. 배설을 위해 노폐물이 이동하는 경로를 **소화계·순환계와 함께** 설명할 수 있어야
   합니다. 한 기관계만 따로 말하면 경로가 끊깁니다.

### 문제

**문제 1.** `자료 변환·해석` `결론·일반화` (옛자료2 31쪽 문제 1)
폐가 한 번 호흡할 때 다음 과정을 거친다. 각 과정 또는 그 사이에서 1) 갈비뼈와 횡격막의
이동 방향, 2) 흉강과 폐 안쪽의 압력 변화 그래프를 적으시오.

> 들숨 시작 → 날숨 시작 → (들숨 시작)

**문제 2.** `적용` `의사소통` (옛자료2 31쪽 문제 2)
단백질이 음식으로 몸에 들어올 때부터 근육 세포에서 에너지로 쓰인 다음 요소의 형태로
몸 밖으로 나갈 때까지, 몸속에서 이동하는 최소 경로를 차례대로 모두 적으시오.

## 옮기면서 한 일

**중단원이 갈라진 것**

15개정 5단원-01 「생물체의 구성 단계와 영양소」는 **두 학년으로 갈라졌다.**

| 옛 자료 | 간 곳 |
|---|---|
| `옛자료2` 26쪽 학습 목표 1, 27쪽 문제 1·2 (기관계) | 중1 Ⅱ-01 생물의 구성 |
| `옛자료2` 26쪽 학습 목표 2, 27쪽 문제 3 (영양소 검출) | 중2 Ⅵ-01 소화와 순환 |

중1 Ⅱ 단원 파일의 「옮기면서 한 일」에 같은 내용이 반대쪽에서 적혀 있다.

**수업에서 주의할 점**

22개정에서 **기관계를 중1 에 배우고 영양소를 중2 에 배운다.** 옛 자료는 둘을 한 중단원에
묶어 「기관계 사이 상호작용」과 「영양소 검출」을 나란히 다루었는데, 이제 한 해 간격이
생긴다. Ⅵ-01 을 시작할 때 중1 Ⅱ-01 의 기관계를 한 번 되짚어야 한다.
