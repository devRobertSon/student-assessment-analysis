## 01. 광합성

| | |
|---|---|
| 교재 | `하이탑2-2` 008~021쪽 |
| 옛 자료 | `옛자료2` 21~23쪽 |

### 학생들의 추가 학습 목표

1. 식물 조직의 종류와 역할을 설명할 수 있어야 합니다. **이 목표는 중1 Ⅱ-01 생물의
   구성에서 이미 다룬 조직계와 이어집니다.** 22개정에서 생물의 구성이 중1 로 내려갔으므로
   여기서는 되짚기만 하면 됩니다.

2. 식물의 광합성이 BTB 용액의 색을 어떻게 바꾸는지 설명할 수 있어야 합니다.

3. 수분이 푸른 염화 코발트 종이의 색을 어떻게 바꾸는지 설명할 수 있어야 합니다.

4. 식물의 종류에 따라 기공이 분포하는 자리가 달라짐을 알고 까닭을 설명할 수 있어야
   합니다.

5. 식물의 광합성 과정에서 에너지가 어떻게 드나드는지 설명할 수 있어야 합니다. 자세한
   내용은 **중3 (16) 화학 반응의 규칙성**을 수강할 때 설명해도 됩니다.

### 문제

**문제 1.** `개념 이해` (옛자료2 22쪽 문제 1)
식물에 있는 조직 다섯 개와 각 조직의 역할을 적으시오.

**문제 2.** `탐구 설계` `자료 변환·해석` (옛자료2 22쪽 문제 2)
식물의 잎을 A) 증류수가 든 비닐과 B) 수산화 칼륨 수용액이 든 비닐 안에 넣고 밀봉한 뒤
LED 전등을 3시간 비췄다. 비닐 속 잎을 각각 C 에 넣어 물중탕한 다음 D 를 떨어뜨려 색
변화를 관찰한다. (수산화 칼륨 수용액은 이산화 탄소를 흡수한다.)

1. C 와 D 가 각각 무엇이고 어떤 역할을 하는지 적으시오.
2. 비닐 A 와 B 의 잎이 다른 색으로 보인다면 어떤 색인지 적고 까닭을 설명하시오.
3. 증류수가 든 비닐 속 잎만으로 LED 전등의 빛 세기를 바꿔 가며 실험하려고 한다.
   화학 반응에 영향을 주는 다른 요인이 무엇인지 적고, 그 요인들을 일정하게 유지하는
   방법과 까닭을 설명하시오.

**문제 3.** `개념 이해` `적용` (옛자료2 22쪽 문제 3)
증산 작용에 대해 답하시오.

1. 증산 작용이 잘 일어나는 조건 중 **증발이 잘 일어나는 조건과 다른 조건** 하나를
   적으시오.
2. (**중3 (16) 화학 반응의 규칙성**을 공부한 이후) 증산 작용이 물리 변화인지 화학
   변화인지 까닭과 함께 밝히고, 증산 작용의 에너지 출입과 같은 에너지가 쓰이는 일상의
   예를 세 가지 설명하시오.

**문제 4.** `문제 인식·가설` `결론·일반화` (옛자료2 23쪽 문제 4)
기공이 분포하는 자리는 식물의 종류에 따라 다르다. 잎이 좁고 위로 서는 외떡잎식물은
앞뒤에 고루, 잎이 넓고 수평으로 나는 쌍떡잎식물은 뒷면에 주로, 수련 같은 수상 식물은
윗면에 주로 분포한다.

1. 쌍떡잎식물의 기공이 뒷면에 주로 있는 까닭을 외떡잎식물과 비교하여 설명하시오.
2. 수상 식물의 기공이 윗면에 주로 있는 까닭과, 1)에서 든 까닭을 해결할 수 있는 수상
   식물 잎의 구조를 설명하시오.

### 교재 서술형 문제

## 02. 식물의 호흡과 에너지

| | |
|---|---|
| 교재 | `하이탑2-2` 022~031쪽 |
| 옛 자료 | `옛자료2` 24~25쪽 (식물의 호흡) |

### 학생들의 추가 학습 목표

1. 식물의 호흡이 BTB 용액의 색을 어떻게 바꾸는지 설명할 수 있어야 합니다.

2. 식물의 광합성과 호흡을 구분하여 설명할 수 있어야 합니다. **일어나는 자리, 시간,
   드나드는 기체, 에너지의 방향** 네 가지로 나누어 말할 수 있어야 합니다.

3. 식물의 호흡 과정에서 에너지가 어떻게 드나드는지 설명할 수 있어야 합니다. 자세한
   내용은 **중3 (16) 화학 반응의 규칙성**을 수강할 때 설명해도 됩니다.

### 문제

**문제 1.** `탐구 수행` `자료 변환·해석` (옛자료2 25쪽 문제 1)
네 시험관 A~D 에 BTB 용액을 넣고 B 에는 숨을 불어넣는다. C 와 D 에는 검정말을 넣고
D 는 암실로 만든다. 햇빛이 잘 드는 곳에 1시간 둔 뒤 각 시험관의 색이 어떤지 적고 까닭을
설명하시오.

**문제 2.** `문제 인식·가설` `의사소통` (옛자료2 25쪽 문제 2)
(**중3 (17) 날씨와 기후변화**를 공부한 이후) 지구 온난화가 이어지면 식물의 광합성과
호흡에 어떤 영향을 줄지 본인의 생각을 적고 까닭을 설명하시오.
