## 01. 전기의 발생

| | |
|---|---|
| 교재 | `하이탑2-2` 102~113쪽 |
| 옛 자료 | `옛자료2` 7~8쪽 |

### 학생들의 추가 학습 목표

1. 대전된 두 물체를 붙였다 뗄 때 **전하량 보존 법칙이 성립함**을 알고 있어야 합니다.

2. 부도체에 대전체를 가까이하면 **유전 분극**이 일어남을 알고 있어야 합니다. 도체의
   정전기 유도와 구분해서 말할 수 있어야 합니다.

3. **심화:** 검전기를 한 종류의 전하로 대전시키는 방법을 설명할 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` `적용` (옛자료2 8쪽 문제 1)
대전이 어떤 현상인지 설명하고 일상생활에서 대전이 일어나는 현상을 두 개 적으시오.

**문제 2.** `탐구 설계` `의사소통` (옛자료2 8쪽 문제 2)
다음 실험 도구로 검전기를 대전시키는 방법을 설명하시오.

> 검전기, (−)전하로 대전된 플라스틱 막대, 금속판

1. (+)전하로 검전기 전체를 대전시키는 방법
2. (−)전하로 검전기 전체를 대전시키는 방법

**문제 3.** `결론·일반화` `문제 인식·가설` (옛자료2 8쪽 문제 3)
전하량이 +3 으로 대전된 고정된 금속 벽 주변에, 전하량이 −5 로 대전된 금속 공이 마찰이
없는 평면 위에 있다. 벽과 공의 크기와 재질이 같을 때 답하시오.

1. 벽과 공이 부딪힌다. 부딪히는 까닭을 설명하시오.
2. 부딪힌 뒤 금속 공의 전하량을 구하시오.
3. 공이 움직이는 방향에 대전되지 않은 고정된 금속 벽이 하나 더 있을 때, 공의 움직임을
   설명하시오.

### 교재 서술형 문제

`하이탑2-2` 112~113쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 02. 전류와 전기 에너지

| | |
|---|---|
| 교재 | `하이탑2-2` 114~131쪽 |
| 옛 자료 | `옛자료2` 9~11쪽 (전압과 전류) |

이름에 「전기 에너지」가 붙으면서 **소비 전력과 전기 에너지의 양**이 들어왔다. 15개정에서
중3 에 있던 내용이다.

### 학생들의 추가 학습 목표

1. 전기 회로의 구성 요소와 각각의 역할을 알고, 물의 흐름에 맞춰 공통점과 차이점을
   설명할 수 있어야 합니다. **차이점까지 말해야** 비유가 어디서 깨지는지 알게 됩니다.

2. 전압계와 전류계의 사용법을 알고, 두 계기가 회로에서 어떤 역할을 하는지 유추할 수
   있어야 합니다.

3. 전지를 직렬로 이을 때와 병렬로 이을 때 회로에 어떤 영향을 주는지 알고 있어야 합니다.

4. 전기 회로에서 합성 저항을 구하는 과정을 설명할 수 있어야 합니다.

5. 전기 회로에서 전류가 나뉘어 흐르는 과정에서도 **전하량 보존 법칙이 성립함**을 알고
   있어야 합니다.

6. 소비 전력의 뜻을 알고, 전기 기구가 1초 동안 쓰는 전기 에너지의 양을 구할 수 있어야
   합니다. **새로 넣은 목표입니다.** 15개정에서는 중3 내용이었습니다.

### 문제

**문제 1.** `결론·일반화` `의사소통` (옛자료2 10쪽 문제 1)
전기 회로를 물의 흐름과 비교하여 나타낸다. 물의 흐름과 전기 회로가 **다른 점**을 세 가지
설명하시오.

**문제 2.** `탐구 설계` `결론·일반화` (옛자료2 10쪽 문제 2)
전압계와 전류계를 회로에 어떻게 이어야 하고 왜 그렇게 이어야 하는지 설명하시오.

1. 전류계: 회로에 (직렬 / 병렬) 연결. 까닭:
2. 전압계: 회로에 (직렬 / 병렬) 연결. 까닭:
3. 실수로 반대로 이었을 때 두 계기의 측정값이 어떻게 달라지는지 설명하시오.

**문제 3.** `적용` `결론·일반화` (옛자료2 10쪽 문제 3)
멀티탭은 여러 콘센트가 있어 일부만 꽂아도 회로에 전류가 흐른다.

1. 멀티탭이 직렬 연결인지 병렬 연결인지 설명하시오.
2. 콘센트를 무한히 늘려 여러 전기 기구를 쓸 수 없는 까닭을 설명하시오.

**문제 4.** `자료 변환·해석` `탐구 설계` (옛자료2 11쪽 문제 4)
3 V, 5 V 전지가 두 개씩 모두 네 개 있다. 1 Ω 저항 한 개에 전지 네 개를 여러 가지로
이어 회로를 만들려고 한다. 저항에 흐를 수 있는 전류의 가짓수를 모두 적고 그때의 전지
배치를 회로 형태로 그리시오. (전지는 큰 전류를 낼 수 있고 저항 말고는 에너지 손실이
없다. 저항은 양 끝만 회로에 이을 수 있다.)

**문제 5.** `자료 변환·해석` `탐구 설계` (옛자료2 11쪽 문제 5)
12 V 전지 하나와 1 Ω 저항 네 개가 있다. 저항의 일부 또는 전부를 여러 가지로 이어 회로를
만들려고 한다. 전지에서 나가는 전류의 가짓수를 모두 적고 그때의 저항 배치를 회로 형태로
그리시오. (조건은 문제 4와 같다.)

`하이탑2-2` 130~131쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 03. 전류의 자기 작용

| | |
|---|---|
| 교재 | `하이탑2-2` 132~145쪽 |
| 옛 자료 | `옛자료2` 12~13쪽 (자기) |

### 학생들의 추가 학습 목표

1. 자석 내부의 자기력선을 그릴 수 있고 **자기력선이 폐곡선임**을 알고 있어야 합니다.
   자석 밖에서는 N 에서 S 로, 안에서는 S 에서 N 으로 이어집니다.

2. 재료를 가지고 간이 전동기를 만들 수 있고 전동기의 원리를 설명할 수 있어야 합니다.

3. 자기력선은 서로 **교차하지 않는다**는 것을 알고 있어야 합니다.

### 문제

**문제 1.** `개념 이해` `자료 변환·해석` (옛자료2 13쪽 문제 1)
자기력선이 무엇인지 설명하고, 자석 바깥과 자석 안에서 자기력선이 향하는 방향을 N극과
S극으로 나타내시오.

**문제 2.** `개념 이해` `결론·일반화` (옛자료2 13쪽 문제 2)
전자석에 대해 답하시오.

1. 전자석이 무엇인지 설명하시오.
2. 전자석이 어떤 모양인지 설명하고 왜 그 모양이어야 하는지 설명하시오.

**문제 3.** `탐구 설계` `탐구 수행` (옛자료2 13쪽 문제 3)
다음 재료로 간이 전동기를 만드는 실험 과정을 설명하시오.

> 에나멜선, 전지, 집게전선 여러 개, 스위치, 사포, 구멍이 뚫린 금속판 2개

**문제 4.** `문제 인식·가설` `결론·일반화` (옛자료2 13쪽 문제 4)
전봇대에 이웃한 두 전선에 전류가 흐른다고 할 때, 전기 안전을 위해 두 전선의 전류가
같은 방향으로 흘러야 하는지 반대 방향으로 흘러야 하는지 짐작하고 까닭을 설명하시오.

`하이탑2-2` 144~145쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 옮기면서 한 일

**확인한 것 하나와 바로잡은 것 하나**

`_목차_대조표.md` 에 「중2 Ⅶ-02 와 Ⅶ-03 중 어디에 전기 에너지의 발생이 들어가는지
확인이 필요하다」고 적어 두었다. 교재 130~131쪽과 144~145쪽을 읽고 확인했다.

**22개정 중2 Ⅶ 에 전자기 유도는 없다.** Ⅶ-02 는 전류·전압·저항과 소비 전력까지고,
Ⅶ-03 은 자기장·전자석·자기력·전동기까지다. 코일과 자석이 함께 나오는 문제가 있지만
모두 **전류가 자기력을 만드는 쪽**이고, 자석을 움직여 전류를 만드는 쪽은 나오지 않는다.

| 옛 자료 | 새 자리 |
|---|---|
| `옛자료3` 6단원-02 중 소비 전력·전기 에너지 | 중2 Ⅶ-02 전류와 전기 에너지 |
| `옛자료3` 6단원-02 중 전자기 유도 (41~42쪽 학습 목표 1, 문제 1·2) | **중2 에 자리가 없다.** 중3 (19) 운동과 에너지로 보는 것이 맞다 |

대조표도 이에 맞춰 고쳤다.

**새로 넣은 것**

- 소비 전력과 1초 동안 쓰는 전기 에너지 (Ⅶ-02 학습 목표 6)
- 자기력선이 교차하지 않는다는 것 (Ⅶ-03 학습 목표 3)
