## 01. 원소와 주기율표

| | |
|---|---|
| 교재 | `하이탑2-1` 184~203쪽 |
| 옛 자료 | `옛자료2` 1~2쪽 (원소) |
| 새로 쓴 곳 | **주기율표.** 15개정 원소 단원에는 없던 내용이다 |

### 학생들의 추가 학습 목표

1. 원소와 원자의 정의를 각각 알고 있고 둘을 구분할 수 있어야 합니다.

2. 여러 물질을 그 물질을 이루는 **원소의 종류로** 분류할 수 있어야 합니다.

3. 원소의 불꽃 반응색으로 어떤 원소가 들어 있는지 알 수 있어야 합니다. **불꽃 반응으로
   가릴 수 없는 원소가 있다는 것**까지 알아야 합니다.

4. 원소 기호를 읽고 쓰는 규칙(첫 글자는 대문자, 가운데 글자는 소문자)을 알고, 베르셀리우스
   이전의 표기 방식과 비교할 수 있어야 합니다. **새로 넣은 목표입니다.**

5. 주기율표에서 **주기(가로줄)와 족(세로줄)이 무엇을 뜻하는지** 알고, 같은 족에 있는
   원소끼리 성질이 비슷한 까닭을 설명할 수 있어야 합니다. **새로 넣은 목표입니다.**

6. **심화:** 1족 원소(리튬, 나트륨, 칼륨)를 기름에 넣어 보관하는 까닭을 원소의 성질과
   엮어 설명할 수 있어야 합니다. **새로 넣은 목표입니다.**

### 문제

**문제 1.** `개념 이해` (옛자료2 2쪽 문제 1)
원소와 원자가 각각 무엇인지 적고 둘의 차이점을 적으시오.

**문제 2.** `개념 이해` `적용` (옛자료2 2쪽 문제 2)
불꽃 반응이 무엇인지 적고 어떤 종류의 원소를 구분할 수 있는지 적으시오. 또 원소와
그 원소의 불꽃 반응색을 다섯 가지 이상 적으시오.

**문제 3.** `탐구 설계` `의사소통` (옛자료2 2쪽 문제 3)
똑딱이 손난로의 재료인 아세트산 나트륨을 준비하려는데 라벨이 손상되어 아세트산 나트륨과
아세트산 칼슘을 구분할 수 없게 되었다. 두 시약은 흰색 고체로 겉으로는 구분할 수 없다.
다음 준비물로 두 시약을 구분하는 방법을 차례대로 설명하시오.

> 준비물: 은박지 그릇, 니크롬선, 가스 점화기, 솜, 묽은 염산, 에탄올

**문제 4.** `탐구 수행` `결론·일반화` (옛자료2 2쪽 문제 4)
물의 전기 분해 실험에서 순수한 물이 아니라 수산화 나트륨을 녹인 물을 쓰는 까닭을
적으시오. 또 (+)극과 (−)극에 모이는 원소의 특징을 각각 두 가지씩 적으시오.

**문제 5.** `자료 변환·해석` `결론·일반화` (새로)
주기율표의 일부에서 A~D 네 원소의 자리가 주어져 있다. 이 중 성질이 비슷한 원소끼리
짝짓고 까닭을 설명하시오. 또 그 짝이 실제로 어떤 성질을 함께 가지는지 한 가지 적으시오.

### 교재 서술형 문제

`하이탑2-1` 202~203쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 02. 물질의 구성 입자

| | |
|---|---|
| 교재 | `하이탑2-1` 204~219쪽 |
| 옛 자료 | `옛자료2` 3~4쪽 (원자와 분자) · `옛자료2` 5~6쪽 (이온) |

15개정 중단원 **둘이 하나로 합쳐졌다.**

### 학생들의 추가 학습 목표

1. **심화:** 원자 모형이 바뀌어 온 과정에서 어떤 과학자가 어떤 실험으로 모형을 바꾸었는지
   설명할 수 있어야 합니다.

2. 돌턴의 입자설 네 가지와, 현대 원자 모형에서 고쳐야 할 점을 알고 있어야 합니다.

3. **심화:** 분자가 아닌 물질에는 무엇이 있고 화학식으로 어떻게 나타내는지 알 수 있어야
   합니다.

4. 여러 원자로 이루어진 분자를 분자식으로 나타낼 수 있어야 합니다.

5. 양이온과 음이온의 표시, 이온으로 이루어진 물질의 이름을 읽는 방법을 알아야 합니다.

6. **심화:** 전해질과 비전해질의 차이를 알고, 전해질이 전극 주변에서 일으키는 화학 반응을
   설명할 수 있어야 합니다.

7. 이온의 앙금 생성 반응으로 어떤 이온이 들어 있는지 알 수 있어야 합니다.

8. **심화:** 앙금 생성 반응에서 알짜 이온과 구경꾼 이온을 알고, 이온이 든 수용액을 계속
   넣을 때 시간에 따른 앙금과 이온 변화 그래프를 그릴 수 있어야 합니다. 농도에 따라
   달라지는 그래프는 **중3 (16) 화학 반응의 규칙성**을 수강할 때 설명해도 됩니다.

### 문제

**문제 1.** `개념 이해` (옛자료2 4쪽 문제 1·2)
분자가 무엇인지 적고 원자와의 차이점을 적으시오. 또 돌턴의 원자설 네 가지를 설명하고
그중 두 가지를 고쳐 다시 적으시오.

**문제 2.** `개념 이해` `적용` (옛자료2 4쪽 문제 3·4·5)
암모니아, 탄산칼슘, 염화수소의 분자식을 적으시오. 또 화학식과 분자식의 차이를 설명하고
분자가 아닌 물질의 예 두 가지를 화학식으로 적으시오. 물질의 분자식으로 알 수 있는 것을
세 가지 이상 적으시오.

**문제 3.** `결론·일반화` (옛자료2 4쪽 문제 6)
숯, 연필심의 흑연, 다이아몬드는 모두 같은 원소로 이루어져 있다. 이 원소가 무엇인지 적고
셋이 서로 다른 특징을 갖는 까닭을 설명하시오.

**문제 4.** `개념 이해` (옛자료2 6쪽 문제 1)
양이온과 음이온의 차이를 설명하고, 원자가 이온이 될 때 변하는 것과 변하지 않는 것을
설명하시오.

**문제 5.** `개념 이해` `결론·일반화` (옛자료2 6쪽 문제 2·3)
전해질과 비전해질을 구분하는 기준을 설명하고 전해질 수용액에서 전류가 흐르는 까닭을
설명하시오. 또 앙금이 무엇인지 설명하고 알짜 이온과 구경꾼 이온의 차이점을 설명하시오.

**문제 6.** `적용` `결론·일반화` (옛자료2 6쪽 문제 4)
(**중3 (16) 화학 반응의 규칙성**을 공부한 이후) 염화나트륨이 물에 녹는 과정이 물리 변화인지
화학 변화인지 적고 까닭을 설명하시오.
