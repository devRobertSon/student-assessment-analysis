## 01. 별

| | |
|---|---|
| 교재 | `하이탑2-2` 160~175쪽 |
| 옛 자료 | `옛자료3` 43~44쪽 |

### 학생들의 추가 학습 목표

1. 연주 시차와 별까지의 거리를 나타내는 단위를 정확하게 알고 있어야 합니다.
   **연주 시차는 시차의 절반**이라는 것을 빠뜨리면 계산이 모두 두 배로 어긋납니다.

2. 별의 밝기와 등급, 거리 사이의 관계를 통해, 일부만 주어진 표에서 나머지 물리량을
   계산하거나 비교할 수 있어야 합니다.

3. 1등급 차이가 밝기 2.5배임을 이용해 **x 등급 차이의 밝기 차**를 구할 수 있어야 합니다.

4. 별의 색과 표면 온도의 관계를 알고, 겉보기 등급과 절대 등급의 차로 거리를 가늠할 수
   있어야 합니다. **새로 넣은 목표입니다.**

### 문제

**문제 1.** `개념 이해` (옛자료3 44쪽 문제 1)
별의 연주 시차에 대해 답하시오.

1. 연주 시차가 무엇인지 적으시오.
2. 연주 시차와 별까지의 거리 사이의 관계를 설명하시오.

**문제 2.** `자료 변환·해석` `결론·일반화` (옛자료3 44쪽 문제 2)
별들의 등급과 색을 나타낸 자료가 있다.

1. 표면 온도가 가장 높은 별을 고르고 까닭을 설명하시오.
2. 지구에서 가장 가까운 별을 고르고 까닭을 설명하시오.

**문제 3.** `자료 변환·해석` `적용` (옛자료3 44쪽 문제 3)
1월과 7월에 북쪽 하늘을 본 관측 자료가 있다. B 는 천구에 고정된 별이며 A 와 B 는 지구
공전 궤도면에 나란히 놓여 있다.

1. 4월과 10월에 별 A 의 위치를 각각 표시하고 B 와의 시차를 각각 구하시오.
2. 별 A 의 절대등급이 1등급이고 별 B 의 겉보기 등급이 3등급일 때, 지구에서 볼 때 A 가
   B 보다 얼마나 밝게 보이는지 구하시오.

### 교재 서술형 문제

`하이탑2-2` 174~175쪽. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 02. 우주

| | |
|---|---|
| 교재 | `하이탑2-2` 176~189쪽 |
| 옛 자료 | `옛자료3` 45~46쪽 |

### 학생들의 추가 학습 목표

1. 은하수가 무엇인지 알고, 계절에 따른 은하수의 변화로 은하 중심의 위치를 알 수 있어야
   합니다.

2. 그림을 보고 성운과 성단을 구분할 수 있어야 합니다. 성운은 방출·반사·암흑으로,
   성단은 산개·구상으로 다시 나눌 수 있어야 합니다.

3. 우주가 팽창하는 것을 도플러 효과로 설명할 수 있어야 합니다. **도플러 효과는 중2 Ⅲ-02
   파동**에서 미리 다룰 수 있습니다. 같은 해 앞 단원이라 이어 가르치기 좋습니다.

4. 우주가 팽창할 때 **중심이 따로 없다**는 것을 설명할 수 있어야 합니다. 어느 은하에서
   보아도 다른 은하가 멀어지는 것으로 보입니다. **새로 넣은 목표입니다.**

### 문제

**문제 1.** `개념 이해` `자료 변환·해석` (옛자료3 46쪽 문제 1)
은하수에 대해 답하시오.

1. 은하수가 무엇인지 적으시오.
2. 은하수는 자정에 궁수자리가 남중할 때 뚜렷하게 보인다. 이때 지구·태양·은하 중심의
   위치 관계를 설명하고 우리나라의 계절이 어떻게 되는지 적으시오.

**문제 2.** `개념 이해` `자료 변환·해석` (옛자료3 46쪽 문제 2)
주어진 천체 다섯 개의 종류가 무엇인지 적고 특징을 적으시오.

**문제 3.** `결론·일반화` `의사소통` (새로)
풍선 표면에 점을 여러 개 찍고 풍선을 불면 모든 점 사이의 거리가 멀어진다. 이 모형으로
우주의 팽창을 설명하고, **우주 팽창에 중심이 없다**는 것을 이 모형으로 어떻게 보일 수
있는지 적으시오.

### 교재 서술형 문제

`하이탑2-2` 189쪽. 다른 중단원보다 적다. 표는 [`_교재_서술형.md`](_교재_서술형.md) 에 있다.

## 옮기면서 한 일

**학년만 내려왔다.** 중단원 이름과 차례가 그대로라 옮기는 일이 거의 없었다.

**같은 학년 안으로 들어온 참조**

도플러 효과는 15개정에서 중1 의 「파동과 소리」에 있었고 이 단원은 중3 이었다. 두 해
간격이었다. 22개정에서는 **둘 다 중2 이고 Ⅲ 과 Ⅷ 이라 같은 해 안에서 이어진다.**
중2 Ⅲ-02 파동의 문제 2번(앰뷸런스 사이렌)이 이 단원의 발판이 된다.

**새로 넣은 것**

- 별의 색과 표면 온도, 겉보기 등급과 절대 등급의 차로 거리 가늠하기 (Ⅷ-01 학습 목표 4)
- 우주 팽창에 중심이 없다는 것 (Ⅷ-02 학습 목표 4, 문제 3)
