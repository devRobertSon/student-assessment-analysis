# 중3 (16) 화학 반응의 규칙성

| | |
|---|---|
| 교재 | **없음.** 2027년에 하이탑 중3 이 나오면 쪽번호를 채운다 |
| 옛 자료 | `옛자료3` 1~8쪽 (1단원 화학 반응의 규칙과 에너지 변화) |

22개정 중3 교과서가 아직 없다. **대단원은 교육과정 문서의 단원 번호와 이름을 쓰고,
소단원은 15개정 이름을 임시로 둔다.** 교과서가 나오면 소단원 이름과 차례, 교재
쪽번호를 채워야 한다.

**단원 이름에서 「에너지 변화」가 빠졌다.** 15개정 「화학 반응의 에너지 출입」이 여기
남는지 아직 모른다. 일단 여기 두고 표시해 두었다. 자세한 것은
[`_목차_대조표.md`](../_목차_대조표.md) 에 있다.

## 01. 물질 변화와 화학 반응식

| | |
|---|---|
| 옛 자료 | `옛자료3` 1~3쪽 |

### 학생들의 추가 학습 목표

1. 물리 변화와 화학 변화를 구분하고 여러 가지 예를 알고 있어야 합니다.

2. **미정계수법**으로 화학 반응식을 완성할 수 있어야 합니다. 계수를 눈으로 맞추는
   방법은 반응물이 셋만 넘어가도 막힙니다.

### 문제

**문제 1.** `자료 변환·해석` `적용` (옛자료3 2쪽 문제 1)
자동차 배기가스의 이산화질소는 사이아누르산으로 없앨 수 있다.

> A) 사이아누르산을 330 ℃ 로 가열하면 아이소사이안산으로 열분해된다.
> B) 아이소사이안산은 배기가스의 이산화질소와 반응하여 질소, 이산화탄소, 수증기를 만든다.
> 화학식 — 이산화질소 NO₂ · 사이아누르산 C₃H₃N₃O₃ · 아이소사이안산 CHNO ·
> 질소 N₂ · 이산화탄소 CO₂ · 수증기 H₂O

화학 반응 A 와 B 를 화학 반응식으로 나타내시오.

**문제 2.** `자료 변환·해석` `결론·일반화` (옛자료3 3쪽 문제 2)
솔베이법은 식염(염화나트륨)과 석회석(탄산칼슘)으로 탄산나트륨을 만드는 공정이다.
단계별 반응이 주어져 있을 때 답하시오.

1. 빈칸 a~e 에 해당하는 물질의 화학식을 쓰시오.
2. a~e 중 둘을 골라 앙금이 만들어지는 화학 반응식을 쓰시오.

## 02. 화학 반응의 규칙

| | |
|---|---|
| 옛 자료 | `옛자료3` 4~6쪽 |

### 학생들의 추가 학습 목표

1. 화학 반응의 규칙 세 가지(질량 보존 법칙, 일정 성분비 법칙, 기체 반응 법칙)가 각각
   어떤 뜻인지 설명할 수 있어야 합니다. **세 규칙이 무엇을 보존하고 무엇을 고정하는지**를
   나누어 말해야 합니다.

2. **심화:** 앙금 생성 반응에서 남는 이온과 반응한 이온을 가릴 수 있어야 합니다.
   이 목표는 **중2 Ⅳ-02 물질의 구성 입자**의 알짜 이온과 구경꾼 이온에서 이어집니다.

### 문제

**문제 1.** `자료 변환·해석` `결론·일반화` (옛자료3 5쪽 문제 1)
A 이온과 D 이온으로 이루어진 화합물 (가)와, B 이온과 C 이온으로 이루어진 화합물 (나)를
섞어 앙금을 만드는 과정이다. (가)는 A 와 D 가 1 : 1, (나)는 B 와 C 가 1 : 1 로 결합해
있다. 실험 ㉡ 에서는 A 와 C 가 모두 반응해 앙금을 만들었다.

1. 실험 ㉠ · ㉡ · ㉢ 에서 각각 용액에 남아 있는 이온을 모두 적으시오.
2. 이온 A 와 C 가 반응하여 생긴 앙금의 화학식을 적으시오.

**문제 2.** `자료 변환·해석` `문제 인식·가설` (옛자료3 6쪽 문제 2)
부피가 같은 강철 용기에 기체 A₂ 와 B₂ 를 넣고 기체 C₂ 의 질량을 달리하며 반응시켰다.
(다)는 C₂ 의 질량을 달리하며 두 기체 중 하나가 모두 반응한 뒤 잰 용기 전체의 압력이다.
(가)와 (나)의 온도는 일정하다.

1. (가)에서 일어나는 화학 반응식을 쓰고 까닭을 설명하시오.
2. (나)에서 일어나는 화학 반응식을 쓰고 까닭을 설명하시오.

## 03. 화학 반응에서의 에너지 출입

| | |
|---|---|
| 옛 자료 | `옛자료3` 7~8쪽 |
| 확인할 것 | 22개정에서 이 소단원이 (16) 에 남는지, 다른 단원으로 가는지 |

### 학생들의 추가 학습 목표

1. 일상생활의 화학 반응을 발열 반응과 흡열 반응으로 구분할 수 있어야 합니다.

2. 반응이 진행될 때의 에너지 변화 그래프를 그릴 수 있고, 그 그래프에서 주변의 온도가
   어떻게 변하는지 읽을 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` `자료 변환·해석` (옛자료3 8쪽 문제 1)
발열 반응과 흡열 반응의 진행에 따른 에너지 변화 그래프를 그리고, 반응으로 생기는 온도
변화를 적으시오.

1. 발열 반응
2. 흡열 반응

**문제 2.** `적용` `결론·일반화` (옛자료3 8쪽 문제 2)
주어진 여행 일기를 읽고 답하시오.

1. 일기의 상황에서 일어날 수 있는 화학 변화 세 가지와 그 공통점을 말하시오.
2. 그 공통점과 반대되는 특징을 갖는 화학 변화의 예를 두 가지 적으시오.

## 옮기면서 한 일

**학년이 그대로다.** 15개정에서도 중3 이었고 22개정에서도 중3 이다.

**이 단원을 가리키는 참조**

다른 학년의 자료가 이 단원을 여러 번 가리킨다. 모두 22개정 표기로 고쳐 두었다.

| 어디서 | 무엇을 |
|---|---|
| 중2 Ⅱ-02 지각의 구성 물질 문제 6 | 방해석의 염산 반응 화학 반응식 |
| 중2 Ⅳ-02 물질의 구성 입자 학습 목표 8, 문제 6 | 농도에 따른 앙금·이온 그래프, 물리 변화와 화학 변화 |
| 중2 Ⅴ-01 광합성 학습 목표 5, 문제 3 | 광합성과 증산 작용의 에너지 출입 |
| 중2 Ⅴ-02 식물의 호흡과 에너지 학습 목표 3 | 호흡의 에너지 출입 |

**남겨 둔 물음**

이 단원의 03 은 15개정 이름이 「화학 반응에서의 에너지 출입」이었다. 22개정 대단원
이름이 「화학 반응의 규칙성」이라 에너지가 빠진 것처럼 보인다. **위 참조 네 개가 모두
에너지 출입을 가리키므로**, 이 소단원이 다른 단원으로 가면 네 곳을 함께 고쳐야 한다.
