# 중3 (18) 수권과 해수의 순환

| | |
|---|---|
| 교재 | **없음.** 2027년에 하이탑 중3 이 나오면 쪽번호를 채운다 |
| 옛 자료 | `옛자료2` 41~44쪽 (7단원 수권과 해수의 순환) |

소단원 이름은 15개정 것을 임시로 쓴다.

**학년이 한 해 올라온 유일한 단원이다.** 15개정에서는 중2 였는데 22개정에서는 중3 이다.
나머지 중3 단원은 모두 15개정에서도 중3 이었다.

## 01. 수권

| | |
|---|---|
| 옛 자료 | `옛자료2` 41~42쪽 |

### 학생들의 추가 학습 목표

1. **염분이 달라지는 요인**을 설명할 수 있어야 합니다. 물이 빠져나가는 쪽(증발, 결빙)과
   들어오는 쪽(강수, 강물 유입, 해빙)으로 나누어 말해야 합니다.

2. 해수와 담수를 나누는 기준을 알고 있어야 합니다.

3. **심화:** 염분비 일정 법칙이 무엇을 뜻하는지 알고, 염분이 다른 바닷물을 섞었을 때
   섞인 물의 염분과 염류의 양을 계산할 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` (옛자료2 42쪽 문제 1)
염류와 염분이 무엇인지 적고 염분비 일정 법칙이 무엇인지 적으시오.

1. 염류
2. 염분
3. 염분비 일정 법칙

**문제 2.** `적용` `결론·일반화` (옛자료2 42쪽 문제 2)
사해를 이루고 있는 물이 해수인지 담수인지 적고, 해수와 담수를 나누는 기준을 설명하시오.

**문제 3.** `자료 변환·해석` `적용` (옛자료2 42쪽 문제 3)
염분 35 ‰ 인 바닷물 1,000 L 와 염분 30 ‰ 인 바닷물 500 L 를 섞었다.
(염화 나트륨은 전체 염류의 70 %를 차지한다.)

1. 섞인 바닷물의 염분을 구하시오.
2. 섞인 바닷물에 든 염화 나트륨의 양을 구하시오.

**문제 4.** `개념 이해` `결론·일반화` (옛자료2 42쪽 문제 4)
해수의 염분이 달라지는 요인을 있는 대로 적고, 각 요인이 염분을 어떻게 바꾸는지 적으시오.

## 02. 해수의 순환

| | |
|---|---|
| 옛 자료 | `옛자료2` 43~44쪽 |

### 학생들의 추가 학습 목표

1. 난류와 한류의 특징을 구분하여 설명할 수 있어야 합니다.

2. 사리와 조금일 때 태양·지구·달의 위치 관계를 설명할 수 있어야 합니다.
   **중1 Ⅶ-02 지구와 달**에서 배운 달의 위상이 그대로 쓰입니다.

3. **심화:** 난류와 한류가 만나는 곳에 좋은 어장이 생기는 까닭을 두 갈래(영양염류,
   수온)로 나누어 말할 수 있어야 합니다.

### 문제

**문제 1.** `결론·일반화` (옛자료2 44쪽 문제 1)
난류와 한류의 수온과 염분이 차이가 나는 까닭을 수온과 염분에 대해 각각 설명하시오.

**문제 2.** `적용` (옛자료2 44쪽 문제 2)
난류와 한류가 주변 연안의 기후에 영향을 준다. 각각 어떤 기후가 만들어지는지 설명하시오.

**문제 3.** `적용` `의사소통` (옛자료2 44쪽 문제 3)
난류와 한류가 어업에 미치는 영향을 설명하고, 난류와 한류가 각각 풍부한 어장을 만드는
까닭을 설명하시오.

**문제 4.** `자료 변환·해석` `결론·일반화` (새로)
사리와 조금에 대해 답하시오.

1. 사리와 조금일 때 태양·지구·달의 위치를 각각 그림으로 나타내시오.
2. 그때 달의 위상이 어떤지 적고, 사리와 조금이 한 달에 몇 번씩 오는지 적으시오.

## 옮기면서 한 일

**학년이 한 해 올라왔다.** 15개정 중2 7단원이 22개정 중3 (18) 이 되었다.

이 때문에 **수업 차례를 다시 짜야 한다.** 15개정에서는 중2 에서 수권을 배우고 중3 에서
기권을 배웠는데, 22개정에서는 둘 다 중3 이다. 기권((17))이 앞, 수권((18))이 뒤다.

**새로 넣은 것**

- 사리와 조금의 위치 관계 (Ⅱ 학습 목표 2, 문제 4). 옛 자료에 학습 목표는 있었는데
  문제가 없었다.
