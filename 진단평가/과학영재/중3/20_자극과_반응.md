## 01. 감각 기관

| | |
|---|---|
| 옛 자료 | `옛자료3` 22~24쪽 |

### 학생들의 추가 학습 목표

1. 감각을 느끼는 과정을 **차례에 맞춰** 설명할 수 있어야 합니다. 자극 → 수용기 →
   감각 신경 → 대뇌의 틀이 다섯 감각에 모두 같게 적용됩니다.

2. 갑자기 어두워질 때, 감기에 걸렸을 때처럼 **변화 때문에 감각이 달라지는 경우**를
   설명할 수 있고, 스스로 조절하는 방법을 알고 있어야 합니다.

### 문제

**문제 1.** `개념 이해` (옛자료3 23쪽 문제 1)
다음 각 감각이 대뇌까지 이르는 과정을 적으시오.

1. 시각
2. 청각
3. 후각
4. 미각
5. 피부 감각

**문제 2.** `자료 변환·해석` `적용` (옛자료3 23쪽 문제 2)
다음 과정을 설명하시오.

1. 밝기가 달라질 때 눈의 명암 조절 (어두워질 때 · 밝아질 때)
2. 물체의 거리가 달라질 때 눈의 원근 조절 (멀어질 때 · 가까워질 때)
3. 위처럼 기존 감각이 변화 때문에 달라져 스스로 조절하는 경우를 하나 더 적으시오.

**문제 3.** `결론·일반화` (옛자료3 24쪽 문제 3)
코감기에 걸려 코가 막히면 냄새를 잘 맡지 못하는 까닭을 적으시오.

## 02. 신경계

| | |
|---|---|
| 옛 자료 | `옛자료3` 25~27쪽 |

### 학생들의 추가 학습 목표

1. 중추 신경계를 이루는 각 기관의 **위치와 역할**을 정확히 알고 있어야 합니다.

2. **심화:** 자율 신경계를 이루는 두 신경의 구조 차이와, 각 신경이 몸에 어떤 영향을
   주는지 설명할 수 있어야 합니다. **한 기관에 두 신경이 반대로 작용한다**는 것이
   핵심입니다.

### 문제

**문제 1.** `개념 이해` (옛자료3 26쪽 문제 1·2)
하나의 뉴런 안에서 신호가 이동할 때의 경로를 적으시오. 또 중추 신경계를 이루는 각
기관의 위치와 역할을 적으시오.

**문제 2.** `자료 변환·해석` `결론·일반화` (옛자료3 26쪽 문제 3)
자율 신경계를 이루는 두 신경 A 와 B 에 대해 답하시오.

1. 두 신경의 구조 차이를 적으시오.
2. 두 신경이 심장 박동과 호흡 운동을 각각 어떻게 조절하는지 표의 빈칸을 모두 채우시오.

**문제 3.** `개념 이해` `적용` (옛자료3 27쪽 문제 4)
무조건 반사에 대해 답하시오.

1. 감각 기관에서 반응 기관까지 무조건 반사가 일어나는 과정을 적으시오.
2. 무조건 반사는 대뇌가 아닌 다른 중추 신경계 기관을 거친다. 그 기관에 따라 세 가지로
   나눌 수 있다. 세 가지를 적고 각각 어떤 반사가 있는지 적으시오.

## 03. 항상성

| | |
|---|---|
| 옛 자료 | `옛자료3` 28~30쪽 |

### 학생들의 추가 학습 목표

1. 호르몬의 이동 과정을 설명할 수 있어야 합니다. **혈액을 타고 온몸을 도는데도 정해진
   기관에서만 작용한다**는 점이 신경과 다른 자리입니다.

2. 몸 안 내분비샘에서 나오는 호르몬의 종류와 역할을 설명할 수 있어야 합니다.

3. 호르몬과 관련된 병의 원인과 증상을 알고 있어야 합니다.

4. **심화:** 몸 안에서 신경과 호르몬으로 체온·혈당량·체액 농도 조절이 일어나는 과정을
   설명할 수 있어야 합니다. 배설계와 이어지는 내용은 **중2 Ⅵ-02 호흡과 배설**에서
   배운 것입니다.

### 문제

**문제 1.** `개념 이해` (옛자료3 29쪽 문제 1·2)
호르몬이 만들어져 작용하기까지의 이동 경로를 적으시오. 또 뇌하수체에서 만들어지는
호르몬 네 가지와 각 호르몬의 기능을 설명하시오.

**문제 2.** `적용` `의사소통` (옛자료3 29쪽 문제 3)
체온 조절 과정을 신경과 호르몬, 작용하는 모든 기관을 넣어 적으시오.

1. 더울 때
2. 추울 때

**문제 3.** `적용` `의사소통` (옛자료3 30쪽 문제 4)
체액 농도 조절 과정을 신경과 호르몬, 작용하는 모든 기관을 넣어 적으시오.

1. 땀을 많이 흘릴 때
2. 물을 많이 마실 때
