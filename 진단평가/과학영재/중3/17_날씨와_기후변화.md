# 중3 (17) 날씨와 기후변화

| | |
|---|---|
| 교재 | **없음.** 2027년에 하이탑 중3 이 나오면 쪽번호를 채운다 |
| 옛 자료 | `옛자료3` 9~17쪽 (2단원 기권과 날씨) |

소단원 이름은 15개정 것을 임시로 쓴다. 교과서가 나오면 이름과 차례를 채운다.

**단원 이름에 「기후변화」가 새로 붙었다.** 15개정 「기권과 날씨」에서 지구 온난화가
한 학습 목표였는데 22개정에서는 단원 이름에 올라왔다. 옛 자료의 지구 온난화 목표를
더 무겁게 다루어야 한다.

---

## 01. 기권과 복사 평형

| | |
|---|---|
| 옛 자료 | `옛자료3` 9~10쪽 |

### 학생들의 추가 학습 목표

1. **온실 효과와 복사 평형을 정확히 구분하여**, 온실 효과가 나타나도 복사 평형은
   이루어진다는 것을 알고 있어야 합니다. 둘을 섞으면 「온실 효과 때문에 지구가 계속
   뜨거워진다」는 잘못된 설명이 나옵니다.

2. 오존층이 없을 때 기권의 온도 변화를 알고 있어야 합니다.

3. **지구 온난화의 음성 피드백 과정**을 설명할 수 있어야 합니다. 온난화를 가속하는
   양성 피드백만 배우면 한쪽만 보게 됩니다.

4. 해수면 상승은 해빙보다 **해수의 열팽창**에 의한 것이 더 크다는 것을 알고 있어야
   합니다. 열팽창은 **중1 Ⅲ-02 비열과 열팽창**에서 배운 것입니다.

### 문제

**문제 1.** `개념 이해` `자료 변환·해석` (옛자료3 10쪽 문제 1)
기권의 층상 구조를 네 층으로 적고, 각 층의 1) 높이에 따른 온도 변화와 2) 특징을 두
가지씩 설명하시오.

**문제 2.** `결론·일반화` (옛자료3 10쪽 문제 2)
오존층의 역할을 적고, 오존층이 없을 때 기권의 높이에 따른 온도 변화가 어떻게 되는지
설명하시오.

**문제 3.** `개념 이해` `결론·일반화` (옛자료3 10쪽 문제 3)
복사 평형이 무엇인지 설명하고, 대기가 없을 때와 있을 때 복사 평형이 어떻게 달라지는지
설명하시오.

**문제 4.** `적용` `의사소통` (옛자료3 10쪽 문제 4)
지구 온난화가 어떤 현상인지 설명하고, 지구 온난화가 가속되는 과정을 두 가지 이상
설명하시오.

## 02. 대기 중의 물

| | |
|---|---|
| 옛 자료 | `옛자료3` 11~13쪽 |

### 학생들의 추가 학습 목표

1. 포화 수증기량 곡선을 해석하여 공기 중 수증기의 특징을 설명할 수 있어야 합니다.

2. 맑은 날과 흐린 날 하루 동안 기온, 상대 습도, 이슬점의 변화를 **그릴 수 있어야**
   합니다. 말로 설명하는 데서 멈추면 안 됩니다.

3. 구름이 생기는 과정을 차례대로 설명하고 **구름 생성 실험을 설계할 수 있어야** 합니다.

4. 구름 속에서 수증기가 과냉각 물방울에서 증발해 빙정으로 승화하는 까닭을 입자의
   결합력으로 설명할 수 있어야 합니다.

### 문제

**문제 1.** `개념 이해` (옛자료3 12쪽 문제 1·2)
공기 중 수증기의 포화 상태가 어떤 상태인지 설명하고, 불포화 상태의 공기를 포화 상태로
만드는 방법 두 가지를 적으시오. 또 상대 습도와 이슬점이 무엇인지 적으시오.

**문제 2.** `자료 변환·해석` `결론·일반화` (옛자료3 12쪽 문제 3)
맑은 날과 흐린 날 하루 동안 기온, 상대 습도, 이슬점의 변화를 적고 까닭을 설명하시오.

1. 맑은 날
2. 흐린 날

**문제 3.** `개념 이해` `탐구 설계` (옛자료3 12쪽 문제 4·5)
구름이 생기는 과정을 차례대로 적으시오. 또 다음 실험 도구로 구름을 만드는 실험을
설계하시오.

> 가지 달린 삼각 플라스크, 플라스크 마개, 고무관, 펌프, 물, 향

**문제 4.** `개념 이해` `결론·일반화` (옛자료3 13쪽 문제 6)
구름에서 비가 내리는 원리 중 빙정설과 병합설을 설명하고, 빙정설에서 빙정이 커지는
까닭을 설명하시오.

1. 빙정설
2. 병합설
3. 과냉각 물방울과 빙정 중 빙정이 커지는 까닭

## 03. 날씨의 변화

| | |
|---|---|
| 옛 자료 | `옛자료3` 14~17쪽 |

### 학생들의 추가 학습 목표

1. 기압을 잴 때 물이 아니라 수은을 쓰는 까닭을 설명할 수 있어야 합니다.
   **중1 Ⅵ-01 기체의 압력과 부피**에서 이미 물었던 것입니다.

2. 풍향을 정확하게 알고 있어야 합니다. **바람이 불어오는 쪽**을 가리키는 말입니다.

3. 폐색 전선이 사라지는 과정과 정체 전선이 오래 머무는 과정을 설명할 수 있어야 합니다.

4. 정체 전선의 어느 쪽에서 비가 오는지 알고 있어야 합니다.

5. 온대 저기압의 발생과 소멸 과정을 설명할 수 있어야 합니다.

6. 편서풍 때문에 온대 저기압이 지나가는 지역에서 온도, 습도, 기압이 시간에 따라 어떻게
   변하는지 설명할 수 있어야 합니다.

### 문제

**문제 1.** `결론·일반화` (옛자료3 15쪽 문제 1)
기압을 잴 때 액체를 물이 아니라 수은으로 쓰는 까닭을 설명하시오.

**문제 2.** `개념 이해` (옛자료3 15쪽 문제 2)
온난 전선과 한랭 전선의 차이를 있는 대로 설명하시오.

**문제 3.** `자료 변환·해석` `결론·일반화` (옛자료3 15쪽 문제 3)
한 지역에서 온대 저기압의 두 전선이 모두 지나갈 때, 전선을 기준으로 온도·습도·기압이
어떻게 달라지는지 설명하시오.

**문제 4.** `결론·일반화` (옛자료3 15쪽 문제 4)
온난 전선과 한랭 전선이 만나 생기는 폐색 전선과 정체 전선 중 유지 기간이 긴 전선을
고르고 까닭을 설명하시오.

**문제 5.** `자료 변환·해석` `적용` (옛자료3 16쪽 문제 5)
비행기에 풍선을 가지고 탔더니 2분까지는 점점 커지다가 그 뒤로는 변하지 않았다. 비행기
고도와 바깥 기압 그래프가 주어져 있을 때 답하시오.

1. 이륙 뒤 시간에 따라 달라지는 풍선 안쪽 압력 변화를 그래프에 선으로 표시하시오.
2. 비행기 안에서 250 mL 유리병에 공기를 담아 닫고, 집에 와서 물이 담긴 그릇에 거꾸로
   세워 뚜껑을 열었더니 50 mL 의 물이 들어갔다. 비행기 안쪽 기압을 구하시오.
   (온도는 같고 집의 대기압은 1기압이며 공기는 물에 녹지 않는다.)

**문제 6.** `자료 변환·해석` `결론·일반화` (옛자료3 17쪽 문제 6)
높이에 따른 기온 분포 그래프가 주어져 있다.

1. 이 지역에는 서로 다른 두 기단이 만나 생기는 전선이 있다. 그래프에 전선을 점으로,
   전선면을 선으로 표시하시오.
2. 이 전선의 종류를 쓰고 까닭을 설명하시오.
3. a, b, c, d 중 비가 내리고 있을 가능성이 가장 낮은 지점을 고르고 까닭을 설명하시오.

## 옮기면서 한 일

**학년이 그대로다.** 15개정에서도 중3 이었다.

**겹치는 문제 하나**

이 단원 03 의 문제 5(비행기 풍선)는 **중1 Ⅵ-01 기체의 압력과 부피의 문제 4와 같은
소재다.** 15개정에서도 중1 자료와 중3 자료에 나란히 있었다. 22개정에서도 그대로 두되,
중1 에서 한 번 풀고 중3 에서 전선 문제와 함께 다시 푸는 차례로 쓰면 된다.
