# 1 조판기에 주는 자료

조판기는 스펙 파일 하나만 읽는다. `생성기/spec_m11.json` 같은 꼴이다.
문제지와 해설지가 같은 파일을 쓴다.

## 맨 위

| 이름 | 무엇 |
|---|---|
| `title` | 시험지 이름. `중1-1 진단평가` |
| `grade` | 학기. `중1-1` |

## 문항마다

| 이름 | 무엇 | 없으면 |
|---|---|---|
| `img` | 문항 조각 파일 경로 | 멈춘다 |
| `unit` | 단원 이름 | 멈춘다 |
| `type` | 주 유형 | 멈춘다 |
| `subType` | 부 유형. 한 걸음으로 끝나는 문항은 비운다 | 비워 둔다 |
| `countAs` | 세는 유형. 비우면 주 유형이다 | 비워 둔다 |
| `level` | 난이도 | 멈춘다 |
| `points` | 배점 | 멈춘다 |
| `essay` | 주관식이면 참 | 거짓으로 본다 |
| `answer` | 정답. `④ 12` | 멈춘다 |
| `ansForm` | 주관식 정답칸에 미리 찍는 꼴. `{}개` · `{} ≤ a ≤ {}` | 빈칸으로 둔다 |
| `steps` | 풀이 단계. 줄 하나가 한 단계다 | 멈춘다 |
| `miss` | 틀렸다면 뒤에 붙는 글 | 멈춘다 |
| `src` | 출처 이름. `중1-1 입학 심화형` | 멈춘다 |
| `srcno` | 출처에서의 문항 번호 | 멈춘다 |

`steps` 와 `miss` 는 `중1-1_문항분석/` 의 문항별 풀이와 주 유형 근거에서 옮긴다.
`type` `subType` `level` `unit` 도 거기서 온다.

**주관식 정답칸에는 학생이 숫자만 쓴다.** 단위와 기호는 `ansForm` 으로 미리
찍는다. `{}` 가 학생이 숫자를 쓰는 자리다. 정답이 `8개` 면 `{}개`, `1/2 ≤ a ≤ 8`
이면 `{} ≤ a ≤ {}` 다. 정답이 숫자뿐이면 적지 않는다. `{}` 에 숫자를 넣으면
`answer` 와 같아야 하고, `checkspec.py` 가 맞춰 본다. 2026년 10월 3일에 원장님이
정했다.

π 와 √ 는 수로 본다. `84π cm²` 는 `{} cm²` 로 두고 학생이 `84π` 를 쓴다.
`(16π + 60) m²` 도 `{} m²` 로 두어 학생이 `16π + 60` 을 쓴다. 칸에
`(□π + □)` 를 찍으면 답의 꼴을 알려 주게 되기 때문이다. `6√3` 도 그대로 쓴다.

숫자로만 낼 수 없는 답은 이렇게 한다. 2026년 10월 3일에 정했다.

| 답 | 정답칸 꼴 | 학생이 쓰는 것 |
|---|---|---|
| 보기에서 고르기 `ㄴ, ㄷ, ㅁ` | 적지 않는다 | `ㄴ, ㄷ, ㅁ` |
| 직선의 방정식 `y = -(5/2)x + 5` | `y = {}x + {}` | `-5/2` 와 `5` |
| 두 값을 차례대로 `평균 87점, 분산 16` | `평균 {}점, 분산 {}` | `87` 과 `16` |

## 값이 정해진 것

| 이름 | 쓸 수 있는 값 |
|---|---|
| `type` · `subType` · `countAs` | 연산 처리 · 공식 활용 · 개념 이해 · 표현 해석 · 규칙 발견 · 근거 제시 · 단계별 해결 · 식 설정 |
| `level` | 표준 · 상 · 최상 |
| `unit` | 그 학기의 단원 이름. 앞 학기에서 가져온 문항은 이름에 `복습` 을 넣는다 |

`countAs` 는 `type` 이나 `subType` 중 하나여야 한다. 둘 다 아니면 멈춘다.

`src` 는 출처 시험지의 이름이다. 입학 TEST 는 한 해를 다루는 것과 한 학기를
다루는 것이 따로 있어 **둘 다 앞에 학기를 붙인다.** `중1-1 입학 심화형` 과
`중1 입학 심화형` 이다. 학기를 안 붙이면 해설에서 두 시험지가 같아 보인다.
단원 TEST 와 총괄 TEST 는 한 학기짜리만 있어 붙이지 않는다.

| 원본 | `src` |
|---|---|
| `중1-1 (심화형).pdf` | 중1-1 입학 심화형 |
| `중1-1 (일반형).pdf` | 중1-1 입학 일반형 |
| `중1 (심화형).pdf` | 중1 입학 심화형 |
| `중1 (일반형).pdf` | 중1 입학 일반형 |
| `중1-1 (심화).pdf` `(응용)` `(기본)` | 총괄 심화 · 총괄 응용 · 총괄 기본 |
| `중1-1 (Ⅰ_ 소인수분해).pdf` 꼴 | 단원 TEST Ⅰ ~ Ⅴ |

## 글로 적는 법

| | 적는 법 | 왜 |
|---|---|---|
| 지수 2~4 | `x²`, `15³` | `¹²³⁴` 는 글꼴에 있다 |
| 지수 5 이상, 0 | `2^20`, `3^12` | `⁰⁵⁶⁷⁸⁹` 는 글꼴에 없다. `solution.py` 의 `marks()` 가 올려 그린다 |
| 아래 첨자 | `a_1`, `a_10` | 아래 첨자 글자는 글꼴에 없다. 같은 `marks()` 가 내려 그린다 |
| 곱하기 | `×` | |
| 가운뎃점 | `·` (U+00B7) | `∙` 는 글꼴에 없다 |
| 근호 | `√5`, `√(36 + 16)` | 덧줄은 `solution.py` 가 근호 안 길이에 맞춰 긋는다. 여러 항이면 괄호로 묶는다 |
| 분수 | `(2a+7)/5`, `√3/2` | `mathtex.py` 가 LaTeX 로 옮겨 위아래로 쌓아 그린다 |
| 지수가 뒤 글자를 물면 | `x²y`, `x^{5}y` | `^5y` 는 `5y` 를 통째로 올려 버린다. 위 첨자 글자가 있으면 그것을, 없으면 중괄호를 쓴다 |
| 순환소수 | `0.7̇8̇` | 순환마디의 첫 숫자와 끝 숫자 뒤에 결합 점 U+0307 을 붙인다 |
| 어림값 | `√5 ≒ 2.24` | `≒` 는 `mkfont.py` 가 그려 넣는다 |

`^` 와 `_` 는 뒤에 붙은 숫자·영문자를 모두 가져간다. `x^2y` 는 `2y` 를 통째로 올려
버리므로 `x² y` 로 적거나 띄우고 적는다.

**근호 안은 괄호로 묶는다.** `√` 뒤에 괄호가 오면 `solution.py` 가 괄호를 떼고
그 안 전체에 덧줄을 긋는다. 괄호가 없으면 이어진 숫자·영문자·소수점까지만
덧줄을 긋는다. 곧 `√5 + 1` 은 5 위에만, `√(5 + 1)` 은 `5 + 1` 위에 긋는다.
덧줄이 괄호가 하던 일을 하므로 인쇄물에는 괄호가 남지 않는다.

**문제지의 문항은 이 표를 따르지 않는다.** 문항은 원본 PDF 에서 꺼내 온 그림이라
글꼴과 상관없다. 위 표는 **해설지에 조판되는 글**에만 쓴다.

## 찍기 전에 봐야 하는 것

1. 문항이 30개이고 번호가 1부터 30까지 빠짐없이 한 번씩인가
2. `app/src/lib/paperRules.ts` 의 `checkPaper()` 를 통과하는가
3. `img` 가 가리키는 파일이 모두 있고 폭이 930px 인가
4. 스펙에 든 모든 글자가 글꼴에 있는가
5. `src` 가 서로 다른 시험지인데 같은 글자로 보이는 짝이 없는가
6. 문항 분석 문서의 줄바꿈이 낱말 가운데를 자르지 않았는가. 조판기는 줄바꿈을
   공백으로 바꾸므로 줄 끝이 `방식` 이고 다음 줄이 `으로` 면 `방식 으로` 로 찍힌다
7. 스펙에 `**` 나 백틱이 남아 있지 않은가. 조판기는 글자를 그대로 찍는다
8. 문자 `x` 가 `×` 로 바뀐 자리가 없는가. `clean()` 이 백틱 안의 ` x ` 를
   곱하기로 보고 바꾸는데, 앞뒤에 셈 기호가 붙어 있으면 두고 본다
9. 곱하기로 적은 ` x ` 가 남아 있지 않은가. 백틱 밖에 적으면 바뀌지 않는다

단원은 교육과정 차례대로, 단원 안에서는 표준 · 상 · 최상 차례로 놓는다.
**형식은 차례에 넣지 않는다.** 1번이 주관식이어도 된다

# 2 문항 조각

## 자르지 않는다. 꺼낸다

원본 시험지 PDF에는 문항마다 그림 하나가 통째로 박혀 있다. 글자를 다시 조판하는
것이 아니라 그 그림을 그대로 꺼내 쓴다. 그래서 원본과 글자 모양이 똑같고, 수식과
그림이 깨지지 않는다.

꺼내는 코드는 `생성기/extract2.py` 다. 하는 일은 이렇다.

1. 쪽 글에서 두 자리 숫자만 있는 줄을 찾는다. 그것이 그 쪽의 문항 번호다.
   번호가 없는 쪽은 정답·해설 쪽이라 건너뛴다.
2. 콘텐츠 스트림의 `cm` 과 `Do` 를 따라가 그림마다 지면 위 자리를 구한다.
   `page.images` 의 차례는 지면 차례와 다르므로 그대로 쓰면 안 된다.
3. 왼쪽 단을 위에서 아래로, 다음 오른쪽 단을 위에서 아래로 늘어놓는다.
4. 그 차례대로 1번에서 찾은 번호와 짝짓는다.
5. 5000바이트 이하는 로고와 쪽 장식이므로 버린다.

## 꺼낸 그림의 크기

| | 값 |
|---|---|
| 폭 | **930px**. 650장이 하나도 어긋나지 않았다 |
| 높이 | 49 ~ 1953px. 가운데가 534px. 문항마다 다르고 그대로 쓴다 |
| 위아래 흰 여백 | 1px 안쪽. 따로 다듬지 않는다 |
| 원본 지면에 놓이는 폭 | 216.5pt |
| 해상도 | `930 ÷ 216.5 = 4.296` 배. 약 309 DPI |

**폭이 930px로 같은 것이 이 규칙의 핵심이다.** 조판기가 조각을 단 폭에 맞춰
늘리기 때문에, 폭이 같아야 인쇄된 글자 크기가 문항마다 같다. 원본 시험지가 모두
A4 2단에 같은 판형이라 이 값이 저절로 맞는다. 입학 TEST, 총괄 TEST, 단원 TEST를
다 재 봤고 전부 같았다.

문제지에서는 조각을 243.64pt 폭에 놓으므로 원본보다 `243.64 ÷ 216.5 = 1.125` 배
크게 인쇄된다. 인쇄 해상도로는 약 275 DPI다.

## 그림에 든 것과 안 든 것

| 든 것 | 문항 글, 선지, 보기 상자, 그림, 그래프 |
|---|---|
| 안 든 것 | 문항 번호, 배점, 단원 이름, 주관식 표 |

안 든 것은 조판기가 그린다. 그래서 번호를 1번부터 다시 매겨도 조각을 고칠 필요가
없다.

객관식을 주관식으로 바꿀 때는 선지 줄을 뗀 조각을 따로 만든다. 원본 조각은 그대로
둔다. `생성기/nochoice.py` 가 글자 줄을 띠로 묶어 맨 아래 띠를 선지 줄 수만큼
떼어 내고, 위아래 흰 여백은 꺼낸 조각과 같이 1px 를 남긴다. 띠를 세는 것이라
뗀 그림은 꼭 눈으로 본다.

`{학기}_{출처}_{번호}.png` 다. 번호는 두 자리로 적는다. `중1-1_A_03.png` 은

교재에 없는 문항이라 따로 읽어야 한다. 2026년 10월 3일에 맞대어 보았다.

선지를 뗀 조각은 이름 뒤에 `_주관식` 을 붙인다. `중1-1_F_04_주관식.png` 다.

## 짝짓기가 맞는지 보는 법

번호 짝짓기가 어긋나면 다른 문항의 그림이 인쇄된다. 눈에 잘 띄지 않으므로
꺼낼 때마다 아래 두 가지를 본다.

1. **쪽마다 그림 수와 번호 수가 같은가.** 다르면 그 쪽은 짝짓기를 믿을 수 없다
2. **쪽을 이어 붙인 번호가 1부터 끝까지 오름차순으로 끊김 없이 이어지는가.**
   문항은 왼단 위에서 아래, 오른단 위에서 아래로 놓이고 번호도 그 차례로
   붙으므로, 끊김이 없으면 짝짓기가 맞는 것이다

원본 43개가 모두 이 둘을 통과했다.

## 글꼴에서 고쳐 쓰는 글자 셋

노토를 그대로 쓰면 안 되는 글자가 셋 있다. `mkfont.py` 가 Regular 와 Bold 를
뽑은 뒤 이 셋을 손본다. 글꼴 파일을 다시 만들면 자동으로 따라온다.

| 글자 | 원래 무엇이 문제였나 | 어떻게 고쳤나 |
|---|---|---|
| `≒` (U+2252) | 노토에 아예 없어 빈칸으로 인쇄된다 | `=` 의 두 막대에 점 둘을 얹어 새로 그린다. 위 점은 왼쪽, 아래 점은 오른쪽이다 |
| 순환소수 점 (U+0307) | 폭은 0인데 그림이 오른쪽에 있어 `0.3̇` 이 `0.3 ̇` 처럼 옆에 찍힌다 | 숫자 폭의 절반만큼 왼쪽으로, 숫자 높이 위로 옮겨 숫자 한가운데 위에 오게 한다 |
| `√` (U+221A) | 갈고리 뒤에 1 em 까지 막대가 붙어 있어 `√5` 가 `√ 5` 로 인쇄된다 | 막대를 잘라 내고 폭을 갈고리에 맞춘다. 덧줄은 조판기가 긋는다 |

**위 점은 왼쪽, 아래 점은 오른쪽.** `≒` 의 점 자리는 맑은 고딕 · 바탕 · 굴림
셋을 재서 정했다. 셋 다 위 점이 왼쪽이고 아래 점이 오른쪽이며, 막대 왼쪽
끝에서 0.11 과 0.89 자리에 온다. 점 지름은 막대 두께의 1.72배(Bold 는 1.44배),
막대와 점 사이는 0.048 em 이다.

**덧줄은 문단과 표에서 따로 그린다.** 문단은 reportlab 의 `<u offset>` 으로
글자 위 0.86 em 에 0.041 em 두께로 긋고, 정답 일람표처럼 문단을 안 쓰는 자리는
`draw_math()` 가 선으로 긋는다. 두 값 모두 원래 `√` 글리프의 갈고리 꼭대기와
막대 두께에서 가져왔다.

**덧줄은 근호 안 글자보다 조금 더 나간다.** 딱 맞춰 끊으면 숫자를 덜 덮은
것처럼 보인다. 원본 교재도 오른쪽으로 더 낸다. `split_root()` 가 근호 안
끝에 줄 안 바뀌는 공백(U+00A0, 0.224 em)을 붙여 그만큼 늘린다. reportlab 은
이 글자에서 줄을 나누지 않으므로 덧줄이 두 줄로 갈라지지 않는다.

## 분수는 LaTeX 로 옮겨 그린다

분수는 위아래로 쌓아야 하는데 글자 조판으로는 `21/2` 처럼 한 줄로 누울 수밖에
없다. `mathtex.py` 가 문서의 표기를 LaTeX 로 옮기고 matplotlib 의 mathtext 로
그려 그림으로 끼운다. 글꼴은 조판에 쓰는 노토 그대로 앉히므로 한글 본문과
서체가 어긋나지 않는다.

**어디가 수식인지는 백틱으로 안다.** 문항 분석 문서에서 백틱으로 감싼 곳이
수식이다. `mkspec.py` 가 백틱을 살려 스펙에 넘기고, `solution.py` 가 그 안만
그린다. CSV 로 나갈 때는 `mkcsv.py` 가 뗀다.

**분수가 든 수식만 그린다.** 그 밖의 것은 글자 조판이 더 낫다. mathtext 의 큰
근호가 노토에 없어 `√49` 의 갈고리와 덧줄이 어긋나는데, 우리 `roots()` 는 그
자리를 정확히 맞춘다.

**못 바꾸는 것은 바꾸지 않는다.** `mathtex.checked()` 는 바꾸기 전후의 기호가
하나라도 빠지거나 늘면 None 을 돌려주고, 조판기는 그때 글자 조판으로
되돌아간다. 인쇄물에 틀린 식이 나가는 것보다 한 줄로 누운 식이 낫다.
2026-09-21 에 조판되는 수식 1354가지로 시험해 1343가지가 바뀌었고, 안 바뀐 11
가지는 집합을 한글로 적은 것이라 글자 조판이 맞다.

**순열·조합은 손대지 않는다.** `C(6, 3)` 과 좌표 `C(0, 5)` 를 가려낼 길이 없다.
잘못 바꾸면 점이 조합으로 인쇄된다.

정답칸에 단위를 미리 찍은 주관식(`ansForm` 의 `{}` 가 하나)은 학생이 칸에 쓰는
값만 적는다. `84π cm²` 는 `84π`, `(16π + 60) m²` 는 `16π + 60` 이다. 일람표는
학생이 쓴 것과 맞춰 보는 자리라 단위가 없어도 되고, 단위는 아래 정답 줄에 그대로
있다. 2026년 10월 3일에 중1-2 11번이 9.5 로 줄여도 잘려 넣었다.

`{}` 가 둘 이상이면 갈린다. `평균 {}점, 분산 {}` 처럼 글로 이름을 붙인 꼴은 값을
차례대로 `87, 16` 으로 적는다. `{} ≤ a ≤ {}` · `y = {}x + {}` 처럼 등호·부등호로
이은 꼴은 값만 늘어놓으면 뜻을 몰라 답 전체를 적는다.

그 밖의 답이 칸 폭에서 34를 뺀 폭을 넘으면 차례로 이렇게 한다.

1. 한글이 없는 답이면 띄어쓰기를 뺀다. `1/2 ≤ a ≤ 8` 은 `1/2≤a≤8` 이 된다
2. 그래도 넘치면 0.5 씩 줄여 9.5 까지 내린다
3. 그래도 넘치면 뒤를 잘라 말줄임표를 붙인다

2026년 10월 3일에 중1-1 29번이 주관식이 되며 `1/2 ≤ …` 로 잘려 1과 2를 넣었다.

**6칸 5줄은 30칸이다.** 시험지가 30문항으로 고정이라 딱 맞는다. 문항 수를 바꾸면
이 표도 함께 고쳐야 한다.

칸이 10칸 3줄이던 때가 있었는데 한 칸이 53pt 라 글자를 키울 수 없었다. 6칸 5줄로

## CSV 열

앱이 읽는 파일이라 열 이름과 차례가 규칙이다. 2026년 9월 21일에 주 유형과 부
유형 열을 더했다.

### 시험지.csv

```
시험지, 과목, 문항번호, 단원, 유형, 주유형, 부유형, 난이도, 형식, 배점,
정답, 출처, 원문항, 문제지, 해설, 출제표
```

### 출제표.csv

```
문항, 단원, 유형, 주유형, 부유형, 난이도, 형식, 배점, 출처, 원문항, 정답
```

| 열 | 무엇을 적나 |
|---|---|
| 유형 | **세는 유형.** 보통은 주 유형과 같고, 부 유형으로 센 문항은 부 유형이다 |
| 주유형 | 늘 주 유형 |
| 부유형 | 부 유형. 없는 문항은 비운다 |

앱은 `유형` 열만 읽고 `주유형` 과 `부유형` 은 아직 읽지 않는다. 모르는 열은
그냥 지나가므로 열을 더해도 앱이 깨지지 않는다. 나중에 리포트에서 부 유형을
쓰기로 하면 그때 앱을 고친다.

## 올리는 곳

`app/public/papers/` 와 `docs/papers/` 다. 저장소의 `.gitignore` 가 `*.csv` 를
막고 있는데 이 두 곳만 예외로 열어 두었다.

**`papers/` 는 공개 사이트로 그대로 나간다.** 학생 이름이 든 파일을 두지 않는다.
