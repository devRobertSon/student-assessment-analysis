않는다. 교재 원문이 그대로 인터넷에 열리기 때문이다.

## 문항 이름 규칙

`중1-1_A_01.png` 은 중1-1 학기, A 출처, 1번 문항이다. 출처 글자와 꺼낸 장수는
`조판규칙.md` 의 2번 묶음에 있다.

`중1-1_F_04_주관식.png` 처럼 뒤에 `_주관식` 이 붙은 것은 객관식 조각에서 선지를
뗀 것이다. 2026년 10월 3일에 중1-1 다섯 장을 만들었다. 원본 조각과 함께 백업한다.

## 생성기

시험지를 찍는 데 쓰는 것이다.

- `spec_m11~m32.json` · `spec_h1.json` · `spec_h2.json`
  여덟 시험지의 30문항 단원·유형·난이도·배점·정답·풀이·오답원인
- `paper.py` · `solution.py` 문제지와 해설 PDF 조판
- `head.py` 1쪽과 2쪽부터의 머리말. 문제지와 해설지가 갖다 쓴다
- `mathtex.py` 분수를 LaTeX 로 옮겨 그림으로 만든다
- `mkfont.py` 가변 글꼴에서 Regular·Bold 를 뽑고 ≒·순환소수 점·근호를 고친다
- `mkcsv.py` 스펙에서 시험지·출제표 CSV 만들기
- `normalize.py` 인쇄 글꼴에 없는 수학 기호 바꾸기
- `poolsheet.py` 한 단원의 문항 풀을 그림째 찍는다. 문항을 바꿀 때 쓴다
- `nochoice.py` 객관식 조각에서 선지 줄을 떼어 `_주관식` 조각을 만든다

봐 가며 쓰는 도구다.

- `ansimg.py` 원본 교재의 정답·해설 쪽을 좌우 반쪽씩 이미지로 뽑는다
- `findglyph.py` 스펙에 쓴 글자 중 인쇄 글꼴에 없는 것을 찾는다
- `checkspec.py` 스펙이 설계 조건을 지키는지 본다
- `synccheck.py` 스펙과 인쇄물이 어긋나지 않았는지 대조한다
- `pairimg.py` · `qmontage.py` 해설을 검증할 때 쓰는 문항 묶음 그림

밑줄로 시작하는 것은 셋뿐이다. `_로고.png` 는 시험지에 넣는 가로 로고,
`_로고a.png` 는 알파 표만, `_수식/` 은 `mathtex.py` 가 쓰는 글꼴과 그림 캐시다.

## 새 컴퓨터, 새 폴더에서 다시 시작하려면

저장소에는 코드와 규칙만 있고 교재 원문은 없다. 그래서 두 가지를 갖춰야 돈다.

1. 저장소를 받는다.
   `git clone https://github.com/devRobertSon/student-assessment-analysis`
2. **이 자료 폴더를 통째로 옮긴다.** 원본·문항·해설·문항분석이 들어 있다.
   OneDrive 로 옮기든 외장 디스크로 옮기든 상관없다.
3. 자료 폴더가 어디인지 알려 준다. 폴더 이름을 바꿔도 되고 어디에 두어도 된다.

       Windows   setx SDA_PAPERS "D:\어딘가\진단평가"
       그 밖에    export SDA_PAPERS=/어딘가/진단평가

   자료 폴더 안에서 그대로 돌릴 때는 안 적어도 된다. `생성기/경로.py` 가 제
   위를 먼저 보고, 그다음 흔히 두는 자리를 찾는다.
4. 무엇이 모자란지 짚어 본다.

       cd <자료 폴더>/생성기
       python doctor.py

   자료 폴더·문항 조각·글꼴·파이썬 꾸러미·스펙을 하나씩 보고, 모자란 것마다
   무엇을 하면 되는지 적어 준다. 마지막 줄이 `다 됐다` 가 되면 찍을 수 있다.
5. 글꼴은 저장소에 없다. `python mkfont.py` 로 다시 만든다.
6. 앱 쪽은 `npm install --prefix app` 한 번이면 된다.

자료 폴더를 잃어버리면 되살릴 길이 없다. **원본·문항·해설은 따로 백업해 둔다.**

## 고친 것을 저장소로 옮기기

생성기나 규칙 문서를 고치면 저장소에도 같은 것이 있어야 한다. 손으로 옮기지
않는다.

    cd <자료 폴더>/생성기
    python sync.py            무엇이 달라지는지 보여 주고 옮긴다
    python sync.py --볼래만    옮기지 않고 무엇이 달라졌는지만 본다

**Claude Code 로 작업할 때는 저절로 된다.** 저장소의
`.claude/settings.json` 에 훅이 걸려 있어, 이 자료 폴더의 파일을 고칠 때마다
`생성기/hook_sync.py` 가 돌아 저장소로 옮긴다. 커밋만 하면 된다.

저장소 자리는 `생성기/sync.py` 가 알아서 찾는다. 다른 곳에 받았으면
환경 변수 `SDA_REPO` 에 적는다.

**교재 원문은 옮기지 않는다.** 옮기기 전에 옮길 것을 한 번 더 훑어 문항 본문이
섞였으면 아무것도 옮기지 않고 멈춘다.
