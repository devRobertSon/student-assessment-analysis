# 진단평가 만드는 자리

`app/public/papers/` 에 올라가 있는 여덟 장을 만드는 코드와 규칙이다.
시험지를 고칠 일이 생기면 여기부터 읽는다.

## 여기 있는 것

| | |
|---|---|
| `설명.md` | 자료가 어디에 무엇이 있는지. 먼저 읽는다 |
| `조판규칙.md` | 문제지·해설지를 늘 같은 모양으로 찍는 규칙. 판형·색·글자·자리 |
| `문항배정_순서.md` | 30문항을 어떤 차례로 고르는지. 13단계 |
| `생성기/` | 시험지 PDF·CSV 를 찍는 파이썬 코드와 여덟 장의 스펙 JSON |
| `단원별_문항수_근거/근거.md` | 단원마다 몇 문항을 넣을지 정한 근거 |
| `{학기}_문항분석/_단계별_결과/` | 고르는 동안 단계마다 남긴 것과 확정된 구성 |
| `_남은세학기_진행.md` · `_네학기더_진행.md` | 여덟 장을 만들며 부딪힌 것과 정한 것 |

## 여기 없는 것

**교재 원문은 이 저장소에 넣지 않는다.** 저장소가 공개라 커밋하면 주소를 아는
누구나 그대로 받는다. 아래는 원장님 컴퓨터의
`OneDrive\Documents\claude\진단평가` 에만 둔다.

| | 왜 |
|---|---|
| `원본/` | 교재 원본 PDF |
| `문항/` · `해설/` | 원본에서 꺼낸 문항·해설 조각 |
| `{학기}_문항분석/` 의 단원별 `.md` | 문항 본문이 그대로 적혀 있다 |
| `_단계별_결과/13_검수용_시험지.md` | 같은 이유 |
| `단원별_문항수_근거/` 의 캡쳐 | 시중 문제집 지면 |
| `생성기/글꼴/` | `mkfont.py` 로 다시 만든다 |
| `생성기/_수식/` | `mathtex.py` 가 쓰는 그림 캐시 |

스펙 JSON 에는 문항 본문이 없다. 단원·유형·난이도·배점·정답·풀이와 문항 그림의
경로만 들어 있고, 정답과 풀이는 이미 해설지로 공개된 것이다.

## 새 컴퓨터, 새 폴더에서 다시 시작하려면

저장소만 받아서는 찍을 수 없다. 교재 원문이 없기 때문이다. 셋만 갖추면 된다.

1. 저장소를 받는다
2. **자료 폴더를 통째로 옮긴다.** 원본·문항·해설·문항분석이 든 폴더다.
   이름을 바꾸든 어디에 두든 상관없다
3. 자료 폴더가 어디인지 알려 준다

```bash
setx SDA_PAPERS "D:\어딘가\진단평가"
```

그다음 무엇이 모자란지 짚어 본다.

```bash
python 진단평가/생성기/doctor.py
```

자료 폴더·문항 조각·글꼴·파이썬 꾸러미·스펙을 하나씩 보고, 모자란 것마다
무엇을 하면 되는지 적어 준다. 마지막 줄이 `다 됐다` 가 되면 찍을 수 있다.

자료 폴더 안에서 그대로 돌릴 때는 `SDA_PAPERS` 를 안 적어도 된다.
[`생성기/경로.py`](생성기/경로.py) 가 제 위를 먼저 보고, 그다음 흔히 두는 자리를
찾는다.

## 찍는 법

```bash
python mkfont.py
```

```bash
python paper.py spec_m11.json <폴더>
```

`solution.py` 는 해설지, `mkcsv.py` 는 시험지·출제표 CSV 를 찍는다. 글꼴은
저장소에 없으므로 `mkfont.py` 를 먼저 한 번 돌린다.

찍은 것을 `app/public/papers/` 로 옮기고 `npm run build --prefix app` 을 돌리면
`docs/` 에 실려 사이트로 나간다.

## 고친 것을 저장소로 옮기기

생성기와 규칙 문서의 본은 자료 폴더 쪽이다. 저장소의 `진단평가/` 는 그 사본이다.
손으로 옮기지 않는다.

```bash
python 진단평가/생성기/sync.py
```

`--볼래만` 을 붙이면 옮기지 않고 무엇이 달라졌는지만 적는다.

**Claude Code 로 작업할 때는 저절로 된다.** `.claude/settings.json` 에 훅이
걸려 있어 자료 폴더의 파일을 고칠 때마다
[`생성기/hook_sync.py`](생성기/hook_sync.py) 가 돌아 저장소로 옮긴다. 커밋만
하면 된다.

교재 원문은 옮기지 않는다. 옮기기 전에 옮길 것을 한 번 더 훑어 문항 본문이
섞였으면 아무것도 옮기지 않고 멈춘다.

## 문항을 바꿀 때

`poolsheet.py` 로 그 단원의 문항 풀을 그림째 뽑아 고르시게 한다.

```
python poolsheet.py spec_h2.json "함수와 그래프" 21,25,28 <폴더> only
```

`only` 를 붙이면 그 자리에 유형·난이도·형식이 맞는 것만 추린다. 붙이지 않으면
그 단원 전체가 나온다. 나온 PDF 에는 교재 원문이 들어 있으므로 저장소에 넣지
않는다.

고른 뒤에는 `app/src/lib/paperRules.ts` 의 `checkPaper()` 로 구성이 규칙에
맞는지 본다.
